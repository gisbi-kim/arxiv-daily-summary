Decision

Geometry must enter action coordinates

MAGP, GeoFF3D, uScenes, Ex-Sim(3)-Reg, GAAT, and underwater or forest deployment papers all attack the same gap: geometry can look consistent while scale, alignment, sensing ambiguity, or onboard constraints make it unusable for robot decisions.

#1Tier A - abstract-only

Beyond Relative Geometry: Metric-Aware Geometry Perception for Robotics

robot geometry - metric scale - action alignment

Status quo belief

Embodied models can use relative reconstruction while leaving scale and distance arbitrary.

Friction / anomaly

The abstract says relative geometry varies across scenes, viewpoints, and input configurations, blocking direct alignment with real-world robot actions.

Hidden premise

A geometry module is useful for action only if object dimensions and distances remain calibrated across the observations that feed the policy.

Conceptual move

Reframe geometry perception from relative 3D reconstruction into metric-aware action support.

Evidence trace

  • [Abstract]The paper identifies arbitrary scale in existing reconstructions as a robotics bottleneck.
  • [Abstract]It frames metric geometry as necessary for actions defined in real-world scale.
  • [Inference]APRL should score geometric perception by action error under scale and viewpoint shifts, not only reconstruction appearance.

Mechanism

The abstract describes an end-to-end plug-and-play framework intended to recover metric geometry that can be aligned with robotic actions.

Falsification frontier

If task success is insensitive to metric calibration after controlling for visual appearance, the metric-aware claim is weaker for that robot task.

Adversarial read

Stress repeated objects, viewpoint changes, object-size priors, and camera intrinsics so relative geometry cannot fake metric consistency.

Transferable thinking tool

Ask whether a recovered scene can name distances in the units the controller uses.

Direct for manipulation, grasping, and navigation; weaker for purely semantic VLM tasks where metric distance is not consumed.

PHR-VLA: Planning Horizon Reasoning for Vision-Language-Action Models

VLA planning horizon - future dynamics - contact-rich manipulation

Status quo belief

Many VLAs condition action prediction primarily on the current observation and instruction.

Friction / anomaly

The abstract argues that contact-rich manipulation requires reasoning over future task dynamics rather than reactive mapping alone.

Hidden premise

A lightweight future head can teach the VLA which latent future state matters without turning deployment into a heavy planner.

Conceptual move

Move VLA supervision from immediate action labels toward privileged planning-horizon representations during training.

Evidence trace

  • [Abstract]The paper states that current-observation conditioning is insufficient for fine-grained contact manipulation.
  • [Abstract]It introduces planning-horizon reasoning through privileged latent future representations.
  • [Inference]APRL should corrupt future state variables and measure when the policy changes before terminal success changes.

Mechanism

The abstract describes aligning internal representations with future dynamics through an auxiliary future head.

Falsification frontier

If horizon representations only improve tasks with obvious scripted sequences, the method may encode dataset phase rather than physical future dynamics.

Adversarial read

Swap visually similar states with different future contact outcomes and compare action deltas against a current-frame baseline.

Transferable thinking tool

Use future-state prediction as a probe of what the action head is allowed to ignore.

Strong for multi-step manipulation; less direct for one-step pick tasks or controllers with explicit model-predictive planning.

Plan Along the Way: Event-Triggered Foundation-Model Planning for TAMP Execution in Partially Observable Manipulation

reactive TAMP - partial observability - event-triggered replanning

Status quo belief

Foundation-model TAMP often assumes a sufficiently specified scene before execution or replans after an obvious failure.

Friction / anomaly

The abstract says a plan may execute successfully yet still be insufficient for task completion when hidden task-relevant objects or conditions are discovered late.

Hidden premise

Replanning should be triggered by newly discovered task relevance, not only by subgoal failure.

Conceptual move

Turn TAMP from one-shot decomposition into event-triggered execution that revises the plan under partial observability.

Evidence trace

  • [Abstract]The paper identifies incomplete scene information as a failure source for TAMP execution.
  • [Abstract]It proposes event-triggered foundation-model planning during manipulation.
  • [Inference]APRL should evaluate whether the trigger fires before wasted motion or unsafe contact, not only whether the final task is solved.

Mechanism

The abstract describes a modular LLM/VLM-guided planning framework that reacts to unseen task-relevant and non-task-relevant objects during execution.

Falsification frontier

If triggers occur only after a subgoal already fails, the method is a late recovery layer rather than an event-aware planner.

Adversarial read

Hide relevant objects, introduce distractors, and perturb discovery order while measuring unnecessary motions, trigger timing, and completion.

Transferable thinking tool

A planner should revise when new evidence changes task sufficiency, not when the robot has already failed.

Direct for partially observable manipulation; weaker for fully observed industrial cells with fixed object inventories.
