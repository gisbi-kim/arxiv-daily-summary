Masked Visual Actions for Unified World Modeling

robot world model - pixel-space action interface - forward and inverse model · abstract · PDF

1. 지배적 믿음

robot world model은 low-level action vector, text instruction, 또는 raw robot state를 외부 조건으로 넣고 video prior와 action space 사이의 표현 mismatch를 감수해 왔습니다.

2. 관찰된 마찰

robot state conditioning은 seen embodiment에서는 작동해도 unseen gripper나 bimanual embodiment에서 training robot을 hallucinate하거나 scene을 변형할 수 있습니다.

3. 숨은 전제

video model의 interaction prior를 쓰려면 action이 model이 학습한 시각 공간 안에서 표현되어야 하며, generated progress는 contact realism으로 다시 평가되어야 합니다.

4. 개념적 이동

action을 숫자 명령이 아니라 partially revealed entity trajectory로 바꾸고, robot motion을 드러내면 forward dynamics model, object motion을 드러내면 inverse model로 씁니다.

5. 작동 메커니즘

DROID와 RoboCasa의 success/failure video에서 segmentation mask와 calibrated robot rendering을 masked visual action으로 만들고, 한 video model을 fine-tune해 scene response를 생성합니다.

6. 결정적 증거와 Evidence Trace

  • Abstract / Figure 1 [Verified]Masked Visual Actions는 arbitrary entity의 partially revealed trajectory를 action interface로 쓰고, 15시간 masked example만으로 multiple embodiment에 적용된다고 설명합니다.
  • Figure 3 / Figure 4 [Verified]forward model은 robot action을 조건으로 scene response를 예측하고, inverse model은 desired object motion에서 robot motion을 합성하는 pipeline으로 제시됩니다.
  • Section 4.1 [Verified]segmentation mask는 calibration 없이 일반적이지만 occlusion leakage와 test-time mask 제공 문제가 있고, rendering은 arbitrary trajectory를 줄 수 있지만 calibration과 robot-only rendering에 묶입니다.
  • Table 1 / Table 2 [Verified]DROID와 unseen BEHAVIOR embodiment에서 baseline보다 좋은 video metrics를 보이고, sparse signal은 held-out DROID에서는 비슷하지만 unseen gripper/embodiment에서는 masked action gap이 커집니다.
  • Figures 10-11 / Limitations [Verified]real rollout progress와 generated progress가 맞지만 positive bias가 있으며, 저자는 model이 causal relation이 아니라 correlation을 학습한다고 명시합니다.

7. Falsification frontier

camera calibration이 조금만 틀어져도 planning value가 무너지거나, generated rollout success가 real contact outcome과 task별로 상관되지 않으면 visual action contract의 독립 가치는 약해집니다.

8. Adversarial read

video model의 positive bias가 policy ranking을 과대평가할 수 있습니다. real robot failure rubric을 contact, object slip, post-contact drift로 분리하지 않으면 imagination score가 deployment evidence처럼 보일 위험이 있습니다.

9. 훔칠 사고 도구

action을 actuator command가 아니라 model이 예측 가능한 visual state intervention으로 재정의하고, generated future를 robot policy의 counterfactual evaluator로 씁니다.

10. Transfer boundary

calibrated external view와 visible robot embodiment가 있는 manipulation에는 직접적이지만, tactile-only contact, deformable object, severe occlusion에서는 visual mask만으로 action-state contract가 부족합니다.

#2Tier A - official arXiv HTML verified

WorldScape Policy 2.0: Empowering Steerable World Action Modeling with Reasoning-Augmented Memory

world action model - event memory - multimodal controllable manipulation · abstract · PDF

1. 지배적 믿음

VLA와 WAM은 현재 observation에서 바로 action을 예측하거나 short video context만 보며, long-horizon task progress와 completed subgoal state를 별도 state로 보존하지 않는 경우가 많습니다.

2. 관찰된 마찰

long-horizon manipulation에서는 같은 tabletop image가 subgoal 전후에 비슷해 보이므로, 현재 frame만 보면 무엇이 이미 끝났고 무엇이 남았는지 구분하기 어렵습니다.

3. 숨은 전제

event boundary와 progress memory가 action generation에 들어가야 visual world model이 passive prediction을 넘어 controllable execution model이 됩니다.

4. 개념적 이동

WAM을 language-only controller가 아니라 short-term visual memory, long-term event memory, latent subgoal reasoning을 가진 steerable world-action model로 재정의합니다.

5. 작동 메커니즘

ManipEvent-5M event segments, multimodal prompts, reasoning-augmented LSTM, causal video-action DiT, embodiment-specific action adapters를 세 단계 curriculum과 semantic forcing으로 묶습니다.

6. 결정적 증거와 Evidence Trace

  • Introduction / Figure 1 [Verified]저자는 기존 WAM의 한계로 progress-aware memory, visual prompt support, explicit subtask semantics 부족을 제시합니다.
  • Section 3 / Figure 3 [Verified]current observation, historical event memory, VLM reasoning branch가 active subgoal을 추론하고, visual prompt는 causal visual prefill 안에 유지됩니다.
  • Section 4.2 [Verified]Qwen3-VL-32B로 event annotation을 만들고, Qwen3-VL-4B가 reasoning backbone으로 쓰이며, WAM은 three-camera visual canvas와 raw action flow matching을 사용합니다.
  • Table 3 / Table 4 [Verified]real PiPER tasks에서 long-horizon folding 75%, shell game 75%, table cleaning 80%, OOD object table-cleaning 60%를 보고하며 baselines보다 높습니다.
  • Table 5 / Table 6 [Verified]STM, LTM, LSR을 차례로 더할수록 clean/randomized average가 오르고, event pretraining과 memory-aware mid-training, semantic forcing이 complementarity를 보입니다.

7. Falsification frontier

event memory를 같은 observation history budget을 가진 non-reasoning recurrent policy와 비교했을 때 gain이 사라지거나, held-out task에서 latent subgoal이 wrong event boundary를 강화하면 memory explanation은 약해집니다.

8. Adversarial read

event annotation이 large VLM으로 만들어진 만큼, semantic forcing gain이 annotation quality와 benchmark overlap에 의존할 수 있습니다. real-world tasks도 PiPER platform과 selected task family에 국한됩니다.

9. 훔칠 사고 도구

world model의 memory를 frame cache가 아니라 completed/remaining subtask state로 다루고, visual prompt를 goal image나 demonstration video와 같은 execution handle로 씁니다.

10. Transfer boundary

structured subtask가 반복되는 manipulation에는 강하지만, open-ended household task에서 event boundary와 subgoal vocabulary가 자동으로 안정화된다고 가정하면 안 됩니다.

1. 지배적 믿음

real2sim은 scene reconstruction과 asset cleanup 뒤 simulator에 넣으면 끝나는 pipeline으로 축소되기 쉽지만, manipulation episode는 geometry뿐 아니라 contact, pose, physical prior, camera setup을 함께 요구합니다.

3. 숨은 전제

4. 개념적 이동

real recording을 observation, actors, geometry, simulator states, physical/alignment parameters, backend, success traces를 포함한 simulatable episode twin contract로 재정의합니다.

5. 작동 메커니즘

visual processing agent, physical-prior inference agent, scene preparation agent, simulator-in-the-loop grasp optimization이 DROID episode를 MuJoCo twin으로 변환합니다.

  • Figure 1 [Verified]raw video에서 segmentation/depth/geometry/pose를 추출하고, material/mass hint를 붙이며, simulator scene과 grasp placement를 critic loop로 보정하는 four-agent architecture를 제시합니다.
  • Section 3 [Verified]episode twin은 observation streams, actors, manipulated entities, geometry, temporal state, physical parameters, simulator backend, conversion metrics/traces를 포함합니다.

7. Falsification frontier

sim twin에서 성공한 policy가 real replay와 연결되지 않거나, VLM decision layer를 deterministic heuristic으로 바꿔도 replay success가 같다면 agentic layer의 연구 가치는 줄어듭니다.

8. Adversarial read

conversion success가 grasp placement optimization에 치우치면 real dynamics recovery가 아니라 simulator fitting일 수 있습니다. 물체 material/mass prior의 error가 downstream policy claim에 얼마나 영향을 주는지 별도 평가가 필요합니다.

9. 훔칠 사고 도구

dataset을 trajectories 묶음이 아니라 replayable episode twin contract로 바꾸고, conversion failure를 visual, physical, alignment, simulator critic stage로 분해합니다.

10. Transfer boundary

rigid-object manipulation episode에는 직접적이지만, deformable contact나 unobserved force state가 핵심인 tasks에서는 visual agent만으로 physical parameter를 신뢰하면 안 됩니다.

3. 숨은 전제

4. 개념적 이동

5. 작동 메커니즘

semi-sparse octree prior가 global SDF value/gradient를 저장하고 neural residual이 fidelity를 보정하며, planner는 clearance로 maximal bubbles를 만들고 overlapping corridor를 최적화합니다.

  • Section 6 overview [Verified]OREN accuracy, online large-environment mapping, Bubble* planning baselines, real quadrotor deployment 순서로 claim을 분리해 평가합니다.
  • Table 1 / Table 2 [Verified]Newer College mesh/SDF metrics에서 OREN이 baseline보다 SDF MAE와 gradient MAE를 개선하고, SDF accuracy가 planner success에 중요하다고 해석합니다.
  • Table 4 / Section 6.3 [Verified]Bubble*는 compact high-clearance corridor와 smooth path를 함께 만들어 A*, RRT, RRT*보다 search+optimization trade-off가 낮다고 보고합니다.
  • Figures 9-10 / Conclusion [Verified]unseen indoor environment에서 SDF mapping과 Bubble* planning을 onboard로 실행하고, 저자는 SDF가 occupancy mapper가 제공하지 못하는 continuous differentiable distances를 제공한다고 결론 냅니다.

7. Falsification frontier

dynamic obstacles, moving sensor artifacts, outdoor LiDAR sparsity에서 SDF gradient error가 planner clearance를 과신하게 만들거나, downstream navigation gain이 occupancy baseline과 같으면 map-planner co-design claim은 약해집니다.

8. Adversarial read

reported real flight는 controlled obstacle setting입니다. unknown dynamic scenes나 severe depth dropout에서 non-truncated SDF의 false free-space가 safety guarantee를 깨는지 따로 stress split이 필요합니다.

9. 훔칠 사고 도구

geometry representation을 visualization asset이 아니라 planner가 consume하는 continuous safety contract로 다루고, map metric을 navigation recovery와 함께 평가합니다.

10. Transfer boundary

depth/LiDAR point-cloud 기반 UAV에는 직접적이지만, semantic manipulation maps나 deformable scene에서는 SDF clearance만으로 task success를 설명할 수 없습니다.

1. 지배적 믿음

language-conditioned robots는 VLM output을 policy prompt나 high-level plan으로 받아들이고, spatial/temporal/logical constraints는 low-level controller가 암묵적으로 맞추기를 기대해 왔습니다.

2. 관찰된 마찰

3. 숨은 전제

4. 개념적 이동

System 2가 instruction을 subtask sequence와 STL specification으로 컴파일하고, System 1이 MPC 또는 learned policy를 실행하면서 STL robustness로 monitoring/replanning합니다.

5. 작동 메커니즘

schema/static checks, deterministic STL compiler, MPC execution, learned policy monitoring, robustness trace feedback을 같은 specification layer로 연결합니다.

6. 결정적 증거와 Evidence Trace

  • Abstract / Figure 1 [Verified]single instruction 안의 temporal and spatial requirements를 STL-annotated subtasks로 나누어 execution and monitoring에 전달한다고 설명합니다.
  • Figure 2 / Section 4.1 [Verified]System 2는 VLM으로 task specification을 만들고, schema/skill/object/constraint checks 후 deterministic STL compiler가 formula를 생성합니다.
  • Figure 4 / Real-world results [Verified]UR3e tabletop tasks에서 STL components를 제거한 VLM-MPC-Cost baseline보다 logical, spatial, temporal constraint groups 전반에서 성공률이 높다고 보고합니다.
  • Section 5.3 [Verified]cube stacking failure에서 STL violation trace는 16 failures 중 12개를 second attempt, 14개를 three attempts 안에 고쳤고, scalar MPC cost baseline은 18 failures 중 7/9개에 그쳤습니다.
  • Limitations [Author claim]현재 learned policies는 STL을 monitoring에만 쓰고 inference-time control signal로 직접 최적화하지 않으며, sequence plan은 branching/cyclic behavior 표현이 제한됩니다.

7. Falsification frontier

cluttered real scenes에서 VLM이 object/predicate grounding을 자주 틀리거나 learned policy가 STL violation을 늦게 감지하면 formal layer가 실제 execution gain으로 이어지지 않습니다.

8. Adversarial read

STL compiler가 가능한 predicate library 안에서만 정확하므로, scene description이 빠뜨린 fine spatial relation은 formal proof처럼 보이지만 실제 world model error를 가릴 수 있습니다.

9. 훔칠 사고 도구

language plan을 자연어 rationale이 아니라 runtime에 계산 가능한 robustness trace로 바꾸고, failure feedback을 constraint/time/margin 단위로 되돌립니다.

10. Transfer boundary

predicate와 controller model이 비교적 명확한 tabletop manipulation에는 강하지만, soft contact, deformable object, open-vocabulary relation에서는 predicate library 확장이 먼저 필요합니다.

Cognitive Dual-Process Planning for Autonomous Driving with Structured Scene Knowledge and Verifiable Reasoning-Action Consistency

autonomous driving - fast/slow VLM routing - rule-verified reasoning · abstract · PDF

1. 지배적 믿음

driving VLM planning은 chain-of-thought가 explicit rationale을 주면 안전해질 것처럼 다루지만, full CoT는 latency를 키우고 rationale과 final action이 충돌할 수 있습니다.

2. 관찰된 마찰

routine scenes에서 slow reasoning은 unnecessary latency를 만들고, complex scenes에서 autoregressive self-routing은 false-negative rate를 제어하기 어렵습니다.

3. 숨은 전제

planning-relevant scene knowledge가 machine-parsable slots로 표현되고 final meta-action과 deterministic rule로 대조될 때, reasoning은 verifiable training signal이 됩니다.

4. 개념적 이동

visual Arbiter가 pre-decoding으로 fast/slow path를 선택하고, slow-path S-CoT output은 rule validator와 GRPO reward로 reasoning-action consistency를 맞춥니다.

5. 작동 메커니즘

foundation perception, critical-path filtering, expert VLM annotation으로 S-CoT supervision을 만들고, Qwen3-VL-4B planner에 fast meta-action and slow structured reasoning prompts를 fine-tune합니다.

6. 결정적 증거와 Evidence Trace

  • Abstract [Verified]manual audit 195 scenes에서 annotation CoT accuracy 91.8%, LCS 98.5%; 574 NAVSIM samples에서 planning accuracy 80.14%, LCS 97.20%, latency 17.39% reduction을 보고합니다.
  • Section 3.3 [Verified]visual Arbiter는 multilevel vision encoder features에서 complexity probability를 내고, complex scene false negative를 penalty로 다룹니다.
  • Section 3.5 / Table 1 [Verified]rule validator는 S-CoT slots와 traffic-scene rules를 parsing해 final meta-action contradiction을 penalty로 주고 RLVR reward에 씁니다.
  • Figure 3 / Table 2 [Verified]complete data engine은 AR/modular pipeline보다 CoT accuracy와 LCS가 높고, GRPO-aligned policy는 SFT baseline보다 LCS를 62.15%에서 97.20%로 올립니다.
  • Table 4 / Limitations [Author claim]external long-tail subsets에서 planning accuracy 65.47%, LCS 85.18%로 낮아지고, 저자는 Arbiter evidence interpretability와 closed-loop driving 검증이 남았다고 밝힙니다.

7. Falsification frontier

rule-consistent S-CoT가 closed-loop trajectory safety를 개선하지 못하거나, traffic-sign/low-visibility subsets에서 routing FNR이 높은 채로 남으면 high-level reasoning contract의 deployment value는 제한됩니다.

8. Adversarial read
