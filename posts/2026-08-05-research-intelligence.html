Quo Vadis, World Modeling?

agent-centric world proxies - feedback interface - world-model design space

Status quo belief

World models are commonly treated as future physical-state predictors.

Friction / anomaly

Improving agents need feedback that is cheaper and safer than direct real-environment interaction.

Hidden premise

The useful proxy can be any interface that gives actionable feedback before real action, not only a predicted video.

Conceptual move

Shift from physical-state prediction to agent-centric world proxies and their functional forms.

Evidence trace

  • [Abstract]The paper says world models offer lower-cost, controllable feedback before real actions.
  • [HTML headings]Official HTML includes Definition and Instantiations sections for agent-centric world proxies.
  • [Inference]APRL should classify WAMs by feedback type: image, state, critic, planner, or monitor.

Mechanism

The official HTML headings lay out motivation, definition, empowerment, instantiations, and design-space conclusion.

Falsification frontier

If proxy feedback does not predict real-world action improvement, the broadened design space becomes taxonomy without leverage.

Adversarial read

A broad proxy definition can hide weak grounding unless every proxy is tied to a success and stop condition.

Transferable thinking tool

Before building a world model, name the feedback channel and the real action it is supposed to change.

Strong for robot learning and agent evaluation; less direct for pure generative-media tasks.

Continue or Replan? Bernoulli-Continuation Policy Learning for Adaptive Horizon Execution

VLA execution horizon - replanning boundary - adaptive control

Status quo belief

Chunk-based VLA policies often execute a fixed number of actions before replanning.

Friction / anomaly

A critical manipulation stage can be executed from a stale chunk if no replanning boundary arrives in time.

Hidden premise

The policy should learn whether its current chunk remains valid.

Conceptual move

Add a Bernoulli continuation decision that adaptively decides continue versus replan.

Evidence trace

  • [Abstract]The paper names fixed execution horizons as task-agnostic periodic schedules.
  • [HTML headings]Official HTML includes Method and Experiments sections.
  • [Inference]APRL should ablate chunk age, continuation probability, and failure onset together.

Mechanism

The official abstract positions BCP as a lightweight plug-and-play adaptive horizon framework.

Falsification frontier

If adaptive replanning only increases compute without improving critical-stage success, the continuation signal is weak.

Adversarial read

A continuation head can learn dataset rhythm rather than true task progress.

Transferable thinking tool

Treat replanning as a learned validity test for the current action chunk.

Strong for chunk-based manipulation; less relevant for continuous MPC controllers.

DRIFT: Derailing Denoising Trajectories of Flow-Matching VLAs with Adversarial Patch Attack

flow-matching VLA security - denoising trajectory - physical attention hijacking

Status quo belief

Flow-matching VLAs have been reported to resist attacks that fool autoregressive VLAs.

Friction / anomaly

Prior attacks can ignore the multi-step denoising ODE where action trajectories are formed.

Hidden premise

Robustness must be tested along the denoising path, not only at the final output.

Conceptual move

Attack the denoising trajectory with a universal adversarial patch on the robot's scene.

Evidence trace

  • [Abstract]The paper says apparent robustness stems from attacks ignoring the multi-step denoising ODE.
  • [HTML headings]Official HTML includes Methodology and Experiments sections.
  • [Inference]APRL should monitor intermediate denoising states for attack or drift evidence.

Mechanism

The official abstract says DRIFT redirects the flow-matching trajectory through test-time input perturbation.

Falsification frontier

If trajectory attacks fail under real camera lighting, viewpoint, and object clutter, physical transfer is limited.

Adversarial read

Patch attacks can overstate risk if they require unrealistic placement or visibility.

Transferable thinking tool

Audit generative policies at every internal refinement step, not only at the emitted action.

Direct for flow-matching VLA policies; less direct for discrete action decoders.
