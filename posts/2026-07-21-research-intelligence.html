오늘 강한 신호는 VLA와 embodied agent 연구가 policy architecture 경쟁에서 execution contract 경쟁으로 이동했다는 점입니다. Foresight Residual RL과 FM-VLA는 성공한 subtask나 현재 image만으로는 contact-rich task의 다음 실패를 설명할 수 없다고 보고, terminal-state quality와 force-history memory를 별도 state로 끌어냅니다. SPARK-VLN과 GeoBoN은 slow reasoning 또는 sampled future를 실행 전에 언제 믿을지 결정하는 selective compute 문제로 바꾸고, DROID-ANCHOR는 monocular geometry를 odometry-anchored metric state로 재정의합니다. APRL 관점의 승부는 더 큰 VLA를 직접 만드는 것이 아니라, handoff quality, memory modality, verification evidence, staleness, metric geometry를 한 evaluation harness 안에 묶어 소유하는 것입니다.

Decision

판세 1 - 성공 여부보다 다음 phase가 쓸 terminal state가 중요하다

Foresight Residual RL은 subtask success가 같아도 downstream success probability가 다르다고 보고, FM-VLA는 visually ambiguous contact event를 force memory로 보존합니다. 장기 조작 평가는 success/fail이 아니라 다음 skill이 소비할 state quality와 hidden contact history를 같이 재야 합니다.

Decision

판세 2 - physical execution은 semantic verifier와 같은 state를 공유해야 한다

PhyAgentOS는 session evidence bundle과 SessionVerifier를 runtime service로 만들고, POT-VLA는 action generation과 predicate verification이 같은 role-indexed 3D object record를 보게 합니다. 이 축은 agent/VLA 연구를 prompt engineering이 아니라 auditable execution system으로 당깁니다.

Decision

판세 3 - test-time compute는 많이 쓰는 것이 아니라 trigger할 조건을 배워야 한다

SPARK-VLN은 slow reasoner의 hidden state를 generation 중간에 streaming하고, GeoBoN은 WAM rollout의 cross-view geometry가 흔들릴 때만 추가 sampling을 씁니다. APRL은 latency, staleness, selective resampling을 closed-loop failure metric과 묶는 쪽이 더 강합니다.

Foresight Residual RL for Long-Horizon Robot Manipulation with Vision-Language-Action Models

long-horizon manipulation - VLA residual RL - terminal-state quality · abstract · PDF

1. 지배적 믿음

long-horizon manipulation은 subtask로 쪼개고 각 subtask success를 올리면 chain success도 오른다고 가정하기 쉽습니다.

2. 관찰된 마찰

저자들은 wrench-screw assembly에서 geometrically successful terminal state라도 다음 insert/rotate phase에는 brittle할 수 있음을 보입니다.

3. 숨은 전제

subtask reward가 terminal state의 downstream usability를 구분하지 못하면, residual RL은 local success만 높이고 전체 task handoff를 망칠 수 있습니다.

4. 개념적 이동

현재 subtask의 terminal image가 다음 subtask success probability를 얼마나 높이는지 offline foresight predictor로 추정하고, 그 값을 residual policy reward multiplier로 씁니다.

5. 작동 메커니즘

terminal states를 base VLA rollout에서 모으고, 다음 phase rollout statistics로 visual foresight predictor를 학습한 뒤, backward induction으로 phase별 residual policy를 훈련합니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]single policy, independent subtask policy, initiation-overlap 방식과 달리 foresight value predictor가 global goal과 local update를 연결한다고 도식화합니다.
  • Figure 2 [Verified]subtask k terminal state를 sampling하고, k+1 rollout success statistics로 foresight predictor를 학습한 뒤 reward를 modulation하는 pipeline을 제시합니다.
  • Table II [Verified]full-task success가 standard residual RL 54.5±3.6%에서 foresight residual RL 85.6±3.9%로 올라갑니다.
  • Table II [Verified]subtask oracle success는 이미 91-99%대라서 개선의 핵심은 individual skill success가 아니라 chained handoff quality입니다.
  • Conclusion / limitations [Author claim]평가는 simulation의 single wrench-screw task와 known phase decomposition에 한정되며, real hardware online RL cost가 주요 obstacle이라고 밝힙니다.

7. Falsification frontier

phase decomposition을 모르는 multi-object task에서 predictor reward가 handoff improvement를 만들지 못하거나, constant sparse reward가 enough exploration으로 같은 full-task success를 달성하면 terminal foresight의 독립 가치는 약해집니다.

8. Adversarial read

single simulated assembly task라 task-specific terminal-state artifact일 수 있습니다. predictor가 image-only라 force/contact state를 놓칠 위험도 있습니다.

9. 훔칠 사고 도구

subtask success를 binary label로 보지 말고, 다음 phase가 소비할 terminal-state quality distribution으로 다시 정의합니다.

10. Transfer boundary

known phase boundary와 cheap downstream rollout이 있는 tasks에는 직접적이지만, unstructured household tasks에는 boundary discovery와 off-policy labeling이 먼저 필요합니다.

PhyAgentOS: A Self-Evolving Operating System for Embodied Agents with Decoupled Cognitive Planning and Physical Execution

1. 지배적 믿음

VLA, world model, agent planner는 각각 model capability로 평가되고, execution verification과 memory consolidation은 주변 glue code로 취급되기 쉽습니다.

2. 관찰된 마찰

physical agents는 task termination과 semantic completion이 다르고, failed run에서 얻은 evidence가 다음 run의 reusable memory로 남지 않는 문제가 반복됩니다.

3. 숨은 전제

embodied intelligence의 최소 단위는 action call이 아니라 intent, target state, runtime evidence, recovery verdict를 담은 session입니다.

4. 개념적 이동

agent layer와 runtime layer 사이를 State-as-a-File protocol로 분리하고, Session-Centered Runtime이 preflight, execution, evidence collection, verifier verdict를 관리합니다.

5. 작동 메커니즘

Markdown/YAML protocol files가 task intent, execution method, target, environment state, lessons를 버전 가능한 cognitive state space로 만들고, SessionVerifier가 evidence-grounded success/failure/replan verdict를 냅니다.

6. 결정적 증거와 Evidence Trace

  • Figure 3 [Verified]agent layer가 executable session을 만들고 runtime layer가 target interaction을 supervise하는 architecture를 제시합니다.
  • Figure 8 [Verified]SessionVerifier가 runtime termination을 자동 success로 보지 않고 task intent, terminal state, evidence bundle을 대조한다고 설명합니다.
  • Table 5 [Verified]CALVIN ABC->D에서 pi0 full-chain success가 38.9%에서 45.6%, pi0.5가 85.3%에서 89.4%로 증가합니다.
  • Table 6 [Verified]RoboCasa365 target50에서 pi0.5 overall success가 17.6%에서 26.8%, RLDX-1이 35.6%에서 42.8%, WorldDreamer가 34.0%에서 42.4%로 증가합니다.
  • Section 6.2 [Author claim]현재 file protocol은 polling 기반이라 latency가 polling interval에 비례하고, event-driven watcher로 바꾸려면 atomic write와 single-writer semantics를 보존해야 한다고 적습니다.

7. Falsification frontier

verifier-triggered recovery gain이 stronger policy retrial, more attempts, 또는 reset budget과 분리되지 않으면 OS abstraction의 핵심 기여가 과장됩니다.

8. Adversarial read

benchmark gains는 대체로 recovery wrapper 효과일 수 있고, semantic verifier의 false positive/negative cost와 real-time safety budget은 더 엄격히 분리해야 합니다.

9. 훔칠 사고 도구

robot agent를 model stack이 아니라 session contract, evidence bundle, acceptance verifier, consolidated memory의 runtime system으로 봅니다.

10. Transfer boundary

APRL의 harness engineering에는 매우 직접적이지만, low-latency control loop 자체를 대체하는 OS로 쓰려면 polling, concurrency, safety certification 문제가 남습니다.

Token-Wise Latent Streaming from Slow Reasoners to Fast Planners for Dynamic Vision Language Navigation

1. 지배적 믿음

VLN model은 instruction reasoning이 끝난 뒤 action을 내는 reason-then-act 구조로 평가되고, simulator는 inference 동안 멈춰 있는 경우가 많습니다.

2. 관찰된 마찰

human-centric dynamic navigation에서는 model이 reasoning하는 동안 pedestrian이 계속 움직이므로, action이 실행될 때 observation이 이미 stale해질 수 있습니다.

3. 숨은 전제

final language answer만 유용한 것이 아니라, autoregressive generation 중간 hidden state가 action-relevant intent를 충분히 일찍 담고 있을 수 있습니다.

4. 개념적 이동

slow VLM reasoner의 intermediate hidden states를 token-wise로 추출해 fixed-size latent slots로 바꾸고, fast flow-matching planner가 inference 중 계속 소비하게 합니다.

5. 작동 메커니즘

Token-Wise Hidden Streamer, Sequence-to-Slot Latent Bridge, Evolving Latent Conditioner가 wait-then-act conditioning을 streaming guidance로 바꿉니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]single-system, blocking dual-system, token-streaming dual-system의 execution timing 차이를 비교합니다.
  • Figure 4 [Verified]pedestrian과 robot이 inference 동안 계속 움직이는 dynamic social VLN benchmark를 제시합니다.
  • Table I [Verified]idealized dynamic environment와 realistic dynamic environment를 분리해 navigation success, social compliance, collision, distance, inference speed를 평가합니다.
  • Introduction / contributions [Verified]wait-then-act transfer보다 token-wise streaming이 SR을 10.0 points 높이고 per-update latency를 0.788s에서 0.185s로 낮춘다고 보고합니다.
  • Section II-C [Verified]기존 dynamic VLN benchmark는 inference 중 environment freezing으로 latency risk를 충분히 측정하지 못한다고 문제를 정의합니다.

7. Falsification frontier

low-level planner가 strong enough해서 language latent 없이도 비슷한 social compliance를 내거나, hidden-state streaming이 unseen social layouts에서 unsafe shortcut을 만들면 약해집니다.

8. Adversarial read

simulator social dynamics와 ORCA pedestrian behavior가 real human hesitation, gaze, negotiation을 충분히 대변하는지는 별도 field validation이 필요합니다.

9. 훔칠 사고 도구

reasoning output을 기다리지 말고, slow process의 intermediate state freshness와 fast planner의 reaction budget을 함께 계측합니다.

10. Transfer boundary

navigation과 driving처럼 latency가 safety-critical인 domains에는 강하지만, contact manipulation에서는 hidden-state semantics보다 force/control feedback이 더 중요할 수 있습니다.

world action model - selective test-time scaling - geometric rollout evaluator · abstract · PDF

1. 지배적 믿음

robot test-time scaling은 더 많은 action candidates를 sampling하고 learned value head나 confidence로 고르는 방향으로 이해되기 쉽습니다.

2. 관찰된 마찰

control에서는 extra compute가 항상 좋은 것이 아니라, action execution 전에 imagined future가 내부적으로 일관적인지 판단해야 합니다.

3. 숨은 전제

WAM은 action chunk와 predicted future observations를 함께 내므로, action score 대신 future geometry consistency가 selector가 될 수 있습니다.

4. 개념적 이동

GeoBoN은 sampled future의 cross-view depth reprojection inconsistency로 candidate를 ranking하고, Gated GeoBoN은 action-future inconsistency가 있을 때만 extra sampling을 trigger합니다.

5. 작동 메커니즘

frozen geometry foundation model로 predicted multi-view futures의 reprojection error를 계산하고, initial rollout이 inconsistent할 때 Nmax candidate pool을 만듭니다.

6. 결정적 증거와 Evidence Trace

  • Table 1 [Verified]RoboCasa, LIBERO Long, RoboTwin 2.0의 five benchmark-backbone settings에서 N=8 fixed-budget GeoBoN이 모두 baseline보다 높은 success를 보고합니다.
  • Abstract [Verified]RoboCasa group average가 Cosmos Policy에서 66.3%->68.4%, X-WAM에서 80.8%->82.5%로 올라갑니다.
  • Abstract / Table 2 [Verified]Gated GeoBoN은 always-on gain의 평균 74.8%를 회복하면서 26.2% decision points에서만 extra sampling을 trigger합니다.
  • Figure 2 / Figure 3 [Verified]candidate budget이 커지면 false low-score selection이 늘어 performance saturation/degradation을 설명하는 failure mode가 됩니다.

7. Falsification frontier

depth reprojection consistency가 robot task success와 상관없는 visually plausible but action-wrong futures를 계속 고르면 zero-shot selector 가치는 제한됩니다.

8. Adversarial read

gain은 크지만 수 percentage-point 수준이고, geometry evaluator가 false low-score outlier를 고르는 failure를 저자들이 직접 보고합니다.

9. 훔칠 사고 도구

test-time compute를 always-on budget이 아니라 predicted future의 self-consistency가 흔들릴 때 쓰는 selective intervention으로 설계합니다.

10. Transfer boundary

multi-view WAM에는 직접적이지만 tactile/contact, language-only state, hidden force event처럼 visual geometry로 보이지 않는 future에는 별도 verifier가 필요합니다.

10. Transfer boundary

DROID-ANCHOR: Odometry-Anchored Recurrent Metric Depth Estimation

1. 지배적 믿음

monocular recurrent SLAM은 robust tracking을 보이더라도 metric scale ambiguity와 drift 때문에 robot navigation state로 바로 쓰기 어렵습니다.

2. 관찰된 마찰

visual-only geometry는 texture, motion, scale ambiguity에 흔들리고, odometry는 noisy하지만 physical scale을 제공한다는 trade-off가 남아 있습니다.

3. 숨은 전제

metric depth를 얻으려면 odometry를 hard truth로 넣는 것이 아니라, uncertainty-aware geometric anchor로 반복 refinement에 주입해야 합니다.

4. 개념적 이동

DROID-style recurrent refinement에 LSTM odometry feature branch와 odometry-aware bundle adjustment backend를 결합해 visual residual과 metric translation residual을 균형화합니다.

5. 작동 메커니즘

high-frequency relative odometry sequence를 spatial feature map으로 broadcast하고, learned heteroscedastic odometry covariance로 wheel-slip/noise 영향을 조절합니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]raw robot odometry를 persistent geometric anchor로 사용해 monocular scale ambiguity를 줄이는 framework를 제시합니다.
  • Figure 2 [Verified]Odom Feature Extractor와 BA_odom backend가 recurrent visual refinement에 metric prior를 주입합니다.
  • Performance table [Verified]TUM-Dataset에서 Droid-SLAM AbsRel 0.617, RMSE 6.800 대비 Droid-Anchor는 AbsRel 0.528, RMSE 1.663을 보고합니다.
  • Table 1 [Verified]LSTM odometry encoder는 mean-pooling ablation AbsRel 1.644, RMSE 7.658 대비 AbsRel 0.528, RMSE 1.663으로 좋습니다.
  • Conclusion and discussion [Author claim]large-scale RGB-D ground truth와 synchronized odometry dataset 부족, platform별 odometry noise profile variance가 generalization 제약이라고 밝힙니다.

7. Falsification frontier

dynamic occlusion, wheel-slip, high-traffic indoor scenes에서 odometry anchor가 wrong metric bias를 넣어 navigation performance를 해치면 core claim이 약해집니다.

8. Adversarial read

Depth Anything V3가 depth metrics 자체에서는 더 낮은 AbsRel/RMSE를 보이므로, robot-facing value는 tracking consistency와 metric SLAM pipeline에서 따로 입증해야 합니다.

9. 훔칠 사고 도구
