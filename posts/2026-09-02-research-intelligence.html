#1Tier A - abstract-only

VOIM: Training-Free Open-Vocabulary 3D Instance Mapping for RGB-D and Monocular SLAM

open-vocabulary 3D instance mapping - deferred labels - voxel evidence accumulation

Status quo belief

Online open-vocabulary mapping often labels instances at first detection, when view evidence is sparse.

Friction / anomaly

The abstract says first-detection commitment is weak and that room scale becomes label-limited while building scale becomes drift-limited.

Hidden premise

A map label should be committed only after enough multi-view voxel evidence has accumulated for the robot's operating scale.

Conceptual move

Move open-vocabulary SLAM from instant 2D label projection to deferred voxel-grounded instance management.

Evidence trace

  • [Abstract]VOIM defers label and instance decisions until multi-view voxel evidence accumulates.
  • [Abstract]The paper reports stronger ScanNet++ mIoU than OVO-SLAM under several perception configurations.
  • [Inference]APRL should treat semantic map labels as release decisions rather than passive annotations.

Mechanism

The abstract describes accumulating soft evidence from off-the-shelf perception per voxel across views, then resolving free-form queries to object instances.

Falsification frontier

If deferred labels do not improve downstream object retrieval or navigation under drift, the mapping gain may stay semantic rather than robot-usable.

Adversarial read

Stress repetitive objects, room-to-building scale drift, monocular-only operation, and query classes that require fine part boundaries.

Transferable thinking tool

Delay semantic commitment until the map has accumulated action-relevant evidence.

Direct for open-vocabulary navigation maps; weaker for short-horizon manipulation where labels are verified by contact.

#2Tier A - abstract-only

HitMem: Hierarchical Temporal 3D Memory with Multi-Modal Context-Aware Retrieval for Dynamic Environments

dynamic 3D memory - stale representation decay - object relocation

Status quo belief

Embodied-agent memory frameworks often assume that mapped objects remain valid until globally re-explored.

Friction / anomaly

The abstract says displaced objects cause memory-observation conflicts, costly geometric recomputation, and inefficient global re-exploration.

Hidden premise

Long-horizon memory is useful only if the agent can tell stale state from recoverable relocation hypotheses.

Conceptual move

Represent 3D memory as a temporal topological graph with decay and specialized retrieval when displacement is detected.

Evidence trace

  • [Abstract]HitMem uses temporal decay to regulate memory activeness and reduce stale representation impact.
  • [Abstract]It reports improved relocation accuracy, exploration cost, and task execution on Dyna-THOR.
  • [Inference]APRL should score memory by recovery value after scene change, not by map completeness.

Mechanism

The abstract describes semantic, spatial, and temporal memory features plus a two-stage retrieval process using trajectory constraints and class affinities.

Falsification frontier

If retrieval succeeds only in simulator-style object moves and fails under real partial observations, the memory contract is too narrow.

Adversarial read

Move objects without direct observation, add semantic distractors, and vary revisit delay to test stale-memory rejection.

Transferable thinking tool

A memory item should expire unless it still helps a later action.

Strong for lifelong ObjectNav and mobile manipulation; less direct for one-shot tasks without revisits.

#3Tier A - abstract-only

REFACTOR-VLA: Unsupervised Library Learning of Typed Motor Programs

typed motor programs - behavioral equivalence - reusable VLA skills

Status quo belief

Many VLA models emit raw actions or short chunks without reusable abstractions, making long-horizon behavior hard to interpret.

Friction / anomaly

The abstract says existing skill-discovery methods avoid the hard question of when two action sequences are behaviorally equivalent for the robot.

Hidden premise

A useful skill library must preserve return and compress behavior only when rollout-equivalence supports the abstraction.

Conceptual move

Learn typed motor-program fragments through a wake/sleep loop and admit abstractions through description-length and return-preservation gates.

Evidence trace

  • [Abstract]Increasing the world model from 188M to 430M worsened performance on all four LIBERO suites.
  • [Abstract]The sleep phase yields a real-LIBERO task-language library and rewrites sampled demonstrations.
  • [Inference]APRL should evaluate skill abstraction by behavioral equivalence and recovery value, not scale alone.

Mechanism

The abstract describes a Behavioral-Equivalence Kernel from learned world-model rollouts and a library-conditioned rectified-flow decoder.

Falsification frontier

If typed abstractions improve imitation metrics but fail under changed object geometry or task order, the library is syntactic rather than behavioral.

Adversarial read

Test whether admitted programs preserve return under unseen object layouts, partial failures, and reordered subgoals.

Transferable thinking tool

Ask when two action sequences are the same behavior for this robot.

Strong for long-horizon manipulation; weaker for reactive control where behavior equivalence is too local.

#4Tier A - abstract-only

EmbodiedSkills: A Unified Framework for Orchestrating, Training, and Deploying VLA Agents

VLA orchestration - prerequisite checks - post-action verification

Status quo belief

Action prediction or model-generated skill selection is often treated as sufficient evidence for execution.

Friction / anomaly

The abstract says long-horizon tasks need perception, planning, execution, verification, and recovery as physical state evolves.

Hidden premise

A VLA action should become executable only after prerequisites are checked and outcome verification is available.

Conceptual move

Treat each skill decision as an execution proposal inside a fixed shared executable-skill interface.

Evidence trace

  • [Abstract]The runtime checks prerequisites before execution and verifies outcomes afterward.
  • [Abstract]The framework records planning, execution, verification, and recovery events as structured trajectories.
  • [Inference]APRL should separate skill proposal quality from execution permission and recovery quality.

Mechanism

The abstract links high-level skill selection, bounded low-level VLA execution, post-action verification, and structured trajectory records.

Falsification frontier

If verification records do not predict or improve recovery on memory-dependent tasks, the agent layer may only document failures.

Adversarial read

Inject stale object state, invalid skill preconditions, and wrong recovery choices to test whether the interface rejects actions before harm.

Transferable thinking tool

Every skill call is a proposal that needs preconditions and an after-action audit.

Direct for VLA agents and skill-based manipulation; less direct for end-to-end reflex policies with no skill boundary.

#5Tier A - abstract-only

Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs

adaptive action chunking - internal attention entropy - online stop signal

Status quo belief

Fixed action chunks trade inference cost against accuracy and can keep executing after observations stop grounding the plan.

Friction / anomaly

The abstract says long chunks become misaligned with newly observed states, while short chunks can create oscillatory behavior.

Hidden premise

The action expert's attention dynamics can reveal when the current observation no longer supports further open-loop execution.

Conceptual move

Use sustained high-entropy plateaus in action-to-observation cross-attention to truncate the execution horizon at inference time.

Evidence trace

  • [Abstract]Cross-attention becomes dispersed and rises toward a plateau as prediction horizon extends.
  • [Abstract]The method improves average task success over fixed-horizon and adaptive chunking baselines.
  • [Inference]APRL should score when a policy stops, not only which action it emits.

Mechanism

The abstract describes a training-free stop mechanism using attention weights already computed by the policy.

Falsification frontier

If attention entropy reacts after physical contact failure has already begun, it is a post-hoc diagnostic rather than a useful stop signal.

Adversarial read

Use visually similar states with different contact constraints to test whether entropy tracks grounding or only sequence length.

Transferable thinking tool

A policy needs a grounded reason to continue open-loop execution.

Strong for chunked VLA manipulation; less direct for controllers with continuous state feedback at every command.

Facet-0: A Robotic Foundation Model for Contact-Rich Precise Manipulation

contact-rich manipulation - action-wrench proposals - precise assembly

Status quo belief

Precise manipulation is often evaluated by task progress or final pose without representing contact consequences explicitly.

Friction / anomaly

The abstract says sub-millimeter assembly needs spatial precision, compliant interaction, and robustness to contact failures.

Hidden premise

A manipulation foundation model should predict the future wrench profile its action is expected to induce.

Conceptual move

Unify multimodal representation learning and RL around joint action-wrench proposals and contact-selective credit.

Evidence trace

  • [Abstract]Facet-0 generates each action chunk with a future wrist-wrench profile.
  • [Abstract]It reports 82 percent mean success on five sub-millimeter computer-assembly tasks.
  • [Inference]APRL should evaluate contact prediction as a first-class action-release variable.

Mechanism

The abstract describes causal wrench history aligned with vision-language semantics, a distributional Action-Wrench Critic, and bounded on-robot adaptation.

Falsification frontier

If wrench prediction helps only the reported assembly cells and fails on new fixtures, the contact representation may be task-specific.

Adversarial read

Hold visual progress constant while changing friction, insertion tolerance, and compliance to see whether contact value changes action choice.

Transferable thinking tool

Treat the expected contact consequence as part of the action.

Strong for force-sensitive assembly; weaker for free-space manipulation with sparse contact.

long-tail driving - counterfactual objects - decision-level affordance prediction

Status quo belief

Friction / anomaly

Evidence trace

  • [Abstract]CoLT-Drive measures whether models predict acceptable longitudinal-lateral action pairs after rare-object insertion.
  • [Abstract]KPA reports higher CoLT-Drive pair accuracy than pretrained and LoRA-SFT baselines.
  • [Inference]APRL should ask whether a perception change actually changes feasible robot action.

Mechanism

OCR reasoning reliability - invalid task detection - root-cause diagnosis

#9Tier A - abstract-only

The Visual Insensitivity Gap: Diagnosing When Vision-Language Models Fail to Use Visual Evidence

VLM visual evidence use - per-sample sensitivity - conditional abstention

Status quo belief

Aggregate multimodal accuracy assumes the model used the image evidence when producing an answer.

Friction / anomaly

The abstract says blurring question-relevant regions can leave next-token distributions nearly unchanged on many samples.

Hidden premise

Reliability needs a sample-level measure of whether visual evidence can actually influence the language output.

Conceptual move

Define the Visual Sensitivity Index as a conditional diagnostic for vision-ignoring failure.

Evidence trace

  • [Abstract]The paper reports visual insensitivity on 40 to 97 percent of samples across six VLMs and three benchmarks.
  • [Abstract]Vision towers can distinguish perturbed images while answer tokens often barely change.
  • [Inference]APRL should measure whether visual cues can veto a robot answer before the action is issued.

Mechanism

The abstract compares perturbation sensitivity, model rankings, vision-tower probes, and answer-token changes across models and benchmarks.

Falsification frontier

If sensitivity does not predict unsafe action decisions, it should be an auxiliary alarm rather than a release gate.

Adversarial read

Blur or mask the exact region that justifies a grasp, turn, or inspection decision and measure whether the command changes.

Transferable thinking tool

Do not trust a visual answer until the relevant visual evidence can change it.

Strong for VLM decision gates; less direct for dense perception modules without language decoding.

StreamScout: Learning When to Look Deeper for Streaming Video Understanding

streaming video understanding - adaptive evidence escalation - token budget control

Status quo belief

Streaming systems often use a fixed-cost memory access procedure for every query.

Friction / anomaly

The abstract says queries differ in the depth of visual evidence required, so memory access depth matters as much as memory content.

Hidden premise

A video agent should stop when current evidence is sufficient and escalate only when the question demands more visual context.

Conceptual move

Turn streaming understanding into a stop-or-escalate cascade over timeline, recent frames, uniform look-back, and salient retrieval.

Evidence trace

  • [Abstract]StreamScout progressively augments a lightweight timeline with deeper visual views only when needed.
  • [Abstract]It reports improved benchmark performance with reduced token use and faster answering on OVO-Bench.
  • [Inference]APRL should score evidence escalation by action error avoided per token or second.

Mechanism

The abstract describes distilling an empirical competence boundary and refining stopping behavior with reinforcement learning.

Falsification frontier

If the stop policy misses rare safety cues, token savings become a deployment risk rather than efficiency.

Adversarial read

Use long robot videos where the decisive event is old, brief, or visually small, and measure premature-stop failures.

Transferable thinking tool

Evidence access has an action-dependent budget, not a fixed recipe.

Strong for long-video robot assistants; less direct for short episodes where all evidence fits in context.
