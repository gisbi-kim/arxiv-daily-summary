#1Tier A - abstract-only

Teach and Grow: An Agent-Centered Architecture for General Robot Learning

general robot learning - skill blocks - retraining tax

Status quo belief

Generalist VLA or world-action policies are often treated as monolithic models that must be retrained when physical coverage is missing.

Friction / anomaly

The abstract frames unfamiliar objects, sensors, embodiments, and contacts as a recurring retraining tax because embodied data must be created by operating machines.

Hidden premise

Reusable closed-loop skill blocks can reduce the need to regenerate robot data when a new scene only requires recomposition or routing.

Conceptual move

Shift the unit of learning from one end-to-end policy to an agent that builds, grounds, composes, and revises executable Skill Blocks.

Evidence trace

  • [Abstract]The paper names the retraining tax as the cost of collecting new robot data, updating policy, and regression testing after coverage failure.
  • [Abstract]It proposes a Skill Library of executable closed-loop behaviors for meaningful subgoals.
  • [Inference]APRL should evaluate whether a skill-block library reduces new-data burden under object, sensor, and contact shifts.

Mechanism

The abstract describes converting a few successful demonstrations into subgoal behaviors, then grounding and composing them with learned or geometric tools while observing physical outcomes.

Falsification frontier

If most new scenes still require new physical data and policy updates, the architecture has not reduced the retraining tax.

Adversarial read

Stress compositional tasks where a reused block is locally successful but globally violates the instruction or contact constraint.

Transferable thinking tool

Measure reuse as physical coverage expansion, not as a larger prompt or longer policy trace.

Strong for modular manipulation and navigation skills; weaker when the task requires a genuinely new contact primitive.

#2Tier A - abstract-only

VLCP: Vision Language Control Policy Closed-Loop Code Replanning for Robot Manipulation

frozen VLM - code policy - closed-loop replanning

Status quo belief

Frozen VLM robot policies are often used open-loop or corrected by retrying a fixed policy or choosing a new subtask.

Friction / anomaly

A failure can live in the generated control function itself, so retrying the same code lets the error compound inside an episode.

Hidden premise

A frontier VLM can use multi-view observations, proprioception, and state deltas to rewrite the failed control code without fine-tuning.

Conceptual move

Move closed-loop correction from subtask selection to the executable code layer.

Evidence trace

  • [Abstract]The paper keeps the VLM frozen and has it emit short Python control functions without demonstrations or fine-tuning.
  • [Abstract]It reports periodic re-observation and code rewriting within a single episode.
  • [Inference]APRL should score when code revision prevents compounding error before terminal failure.

Mechanism

The abstract says the VLM re-observes every K steps and rewrites the Python control function from the current scene and state delta.

Falsification frontier

If code rewrites mainly succeed by restarting simple subtasks rather than repairing the failed control law, the claimed correction level is weaker.

Adversarial read

Use tasks with misleading partial progress where rewriting code can break a previously valid contact or grasp state.

Transferable thinking tool

Localize a robot failure to the interface that can still be rewritten safely during execution.

Strong for scripted or tool-callable manipulation; weaker for high-rate force control where code generation latency is unacceptable.

#3Tier A - abstract-only

MANIGUARD: A Benchmark and Data Suite for Specification-Grounded Safety Evaluation and Improvement of Robotic Manipulation

manipulation safety - LTL monitors - OOD perturbations

Status quo belief

Manipulation policies are commonly ranked by task success, while safety is inferred from aggregate behavior or learned judges.

Friction / anomaly

A robot can complete a task while violating a contact, ordering, or workspace constraint that should have been specified independently.

Hidden premise

Safety must be monitored by explicit physics-grounded predicates while task success and OOD perturbation are held apart.

Conceptual move

Make safety specification an independent evaluation object with locked tasks, single-axis perturbations, and runtime automaton monitors.

Evidence trace

  • [Abstract]The benchmark organizes contact-rich household manipulation into a skill by constraint taxonomy.
  • [Abstract]Each task is evaluated under one in-distribution and four single-axis OOD perturbations with the safety specification fixed.
  • [Inference]APRL should require safety predicates that can fail even when final task success is true.

Mechanism

The abstract describes 200 locked base tasks, four OOD perturbations per task, and LTLf-grounded automaton monitors over physics-grounded predicates.

Falsification frontier

If predicate violations do not predict real robot damage, instability, or operator rejection, the specification is too formal but not physical enough.

Adversarial read

Stress policies that exploit simulator tolerances, graze forbidden objects, or satisfy a goal after a transient unsafe contact.

Transferable thinking tool

Separate task success from specification satisfaction before ranking robot policies.

Strong for manipulation with clear physical predicates; less direct for open-ended social or language-only safety claims.

#4Tier A - abstract-only

Calibrated Predictive Safety for Heterogeneous Robots: An Action-Conditioned JEPA Framework with Model-Based Safety Shields

action-conditioned world model - risk prediction - safety shield

Status quo belief

VLA policies generalize but do not certify execution-time risk, while classical planners respect constraints but do not transfer broadly.

Friction / anomaly

A proposed action chunk can look semantically right while being physically unsafe for a specific embodiment.

Hidden premise

A frozen-encoder latent rollout can predict both progress and risk before execution when conditioned on action and embodiment.

Conceptual move

Turn safety into a receding-horizon candidate-filtering contract: propose actions, roll them forward, score risk and progress, then shield per embodiment.

Evidence trace

  • [Abstract]The paper explicitly contrasts broad VLA generalization with lack of execution-time guarantees.
  • [Abstract]It proposes a pipeline that filters candidate chunks with calibrated risk, progress, uncertainty, and an embodiment-specific shield.
  • [Inference]APRL should compare risk prediction lead time against shield intervention and final task success.

Mechanism

The abstract describes K candidate action chunks, an action-conditioned JEPA, calibrated risk and progress heads, and deterministic safety shields.

Falsification frontier

If the shield dominates decisions and the learned rollout adds little discrimination, the JEPA is not carrying safety authority.

Adversarial read

Use heterogeneous robots with similar observations but different kinematic limits so false embodiment generalization becomes visible.

Transferable thinking tool

Score an action before execution by both expected progress and embodiment-specific inadmissibility.

Strong for chunked robot policies; weaker for continuous contact regimes without reliable candidate rollouts.

#5Tier A - abstract-only

Scalix: Uncertainty-Aware Scale-Consistent Monocular SLAM

monocular SLAM - metric scale - uncertainty-aware factor graph

Status quo belief

Monocular SLAM is attractive for compact robots but suffers scale ambiguity, while learned depth can be noisy and scale-inconsistent.

Friction / anomaly

Robots under constant-velocity motion or sparse sensing can lose observability exactly when reliable metric scale is needed.

Hidden premise

Learned depth is useful only if its per-pixel and per-frame uncertainty can be represented inside geometric optimization.

Conceptual move

Fuse learned depth cues into a probabilistic factor-graph SLAM formulation with explicit scale and depth uncertainty.

Evidence trace

  • [Abstract]The paper identifies scale ambiguity and noisy scale-inconsistent learned depths as the target failure.
  • [Abstract]It integrates learned depth cues into a probabilistic factor-graph formulation.
  • [Inference]APRL should evaluate whether uncertainty-aware scale improves downstream navigation, not only trajectory error.

Mechanism

The abstract describes augmenting monocular depth models with per-pixel depth uncertainty and per-frame scale uncertainty for real-time metric-scale estimation.

Falsification frontier

If scale consistency improves on benchmarks but fails under textureless, dynamic, or rolling terrain scenes, the uncertainty model is incomplete.

Adversarial read

Separate depth noise, scale drift, constant-velocity motion, and dynamic object contamination in controlled robot routes.

Transferable thinking tool

A learned geometry prior becomes robotic only when its uncertainty enters the estimator.

Strong for camera-only mobile robots; less direct when LiDAR or wheel odometry already supplies reliable metric scale.

#6Tier A - abstract-only

Initialization-Free Bundle Adjustment Revisited: A Controlled Experimental Study

bundle adjustment - optimization reconstruction gap - controlled geometry evaluation

Status quo belief

Initialization-free bundle adjustment is often judged by whether the optimization objective reaches a low value from random camera configurations.

Friction / anomaly

A low object-space error can correspond to projective solutions that are not valid metric 3D reconstructions.

Hidden premise

Geometry optimization needs a reconstruction-validity check, not only an optimizer-success check.

Conceptual move

Evaluate InitFree BA with controlled ground truth that exposes the optimization-reconstruction gap.

Evidence trace

  • [Abstract]The paper says existing evaluations primarily measure optimization success.
  • [Abstract]It reports a previously overlooked gap between low OSE and valid Euclidean reconstruction.
  • [Inference]APRL should require metric validity tests for any reconstruction used by a robot map or planner.

Mechanism

The abstract describes a unified framework combining OSE formulations with a Blender-based dataset generator with exact ground truth and controlled camera configurations.

Falsification frontier

If metric invalidity appears only in artificial camera setups, the practical risk for field reconstruction may be smaller.

Adversarial read

Test sparse views, repeated structure, planar scenes, and robot camera motion where low objective values can hide wrong scale or pose.

Transferable thinking tool

Do not treat a converged geometry objective as a robot-usable map without a metric reconstruction check.

Strong for SfM/SLAM evaluation; less direct for pure novel-view synthesis where metric use is not claimed.

#7Tier A - abstract-only

If, Then, Otherwise: Diagnosing Conditional Branching in Vision-Language Navigation

VLN - conditional branching - scene graph predicates

Status quo belief

Vision-language navigation benchmarks usually reward following route-like instructions toward a fixed goal.

Friction / anomaly

Real instructions can require if-then-otherwise branching, where the agent must observe evidence, choose a logical branch, and execute it.

Hidden premise

A navigation failure should be decomposed into perception, grounding, logical branch choice, and motion execution.

Conceptual move

Build scene-graph-grounded conditional instructions with controlled branch depth, dependency length, spatial composition, and evidence observability.

Evidence trace

  • [Abstract]The paper states that existing evaluations provide limited control over conditional branch execution.
  • [Abstract]It grounds branch conditions in verifiable 3D scene-graph predicates.
  • [Inference]APRL should report whether an embodied agent chose the wrong branch or failed after a correct branch.

Mechanism

The abstract introduces CondVLN, generated from verifiable 3D scene-graph predicates with controlled branching variables.

Falsification frontier

If branch failures collapse to ordinary perception misses, the logical diagnostic value is weaker than claimed.

Adversarial read

Use conditions where the relevant evidence is partly observable, temporally delayed, or conflicts with a language prior.

Transferable thinking tool

Make the decision branch itself an evaluated object before measuring navigation success.

Strong for VLN and mobile manipulation instructions; weaker for reactive locomotion without symbolic conditions.

#8Tier A - abstract-only

Which Source Wins? Task-Dependent Reliance in Vision-Language Models

VLM reliability - modality conflict - task-dependent source reliance

Status quo belief

VLMs are often assumed to fuse image and text evidence in a stable way across tasks.

Friction / anomaly

When image and text conflict and one source becomes harder to read, the model may shift reliance differently depending on task and evidence structure.

Hidden premise

Reliance is not a fixed model property; it is a task-conditioned arbitration behavior that must be tested under controlled conflict.

Conceptual move

Create paired conflicts and degrade one modality at a time to measure source preference shifts.

Evidence trace

  • [Abstract]The paper reports opposite reliance-shift patterns between arithmetic conflicts and ChartQA-Conflict.
  • [Abstract]The reversal persists after calibration for unimodal accuracy loss and after replacing charts with table images.
  • [Inference]APRL should treat modality authority as an evaluated variable in robot perception-language systems.

Mechanism

The abstract describes conflicts from arithmetic and ChartQA settings, legibility degradation, generated answers, and likelihood margins.

Falsification frontier

If source-reliance shifts do not predict action errors in embodied tasks, the diagnostic may remain VQA-specific.

Adversarial read

Use robot scenes where text instructions, gauges, labels, or charts conflict with visual evidence under controlled degradation.

Transferable thinking tool

Ask which source wins under conflict before trusting a multimodal explanation.

Strong for VLM-heavy inspection and navigation; less direct for low-level policies that do not arbitrate text and image evidence.
