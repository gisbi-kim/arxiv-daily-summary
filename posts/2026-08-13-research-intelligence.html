#1Tier A - abstract-only

StellaVLA: In-Context Structured Demonstration for Generalizable Vision-Language-Action Models

VLA test-time adaptation - structured demonstrations - cross-embodiment transfer

Status quo belief

VLA adaptation often means collecting more task data or fine-tuning after the policy fails out of distribution.

Friction / anomaly

A raw demonstration can show what happened without explaining the task plan, sub-goals, or 3D motion that should transfer to a new embodiment.

Hidden premise

A retrieved trajectory becomes reusable only if it is converted into structured task evidence rather than copied as pixels and actions.

Conceptual move

Use an offline pipeline to turn a raw trajectory into a task plan, sub-goal descriptions, and verbalized 3D motion for in-context VLA guidance.

Evidence trace

  • [Abstract]The paper states that VLA performance often collapses when scene, viewpoint, or object differs from training.
  • [Abstract]It converts raw trajectories into structured demonstrations at zero human-annotation cost.
  • [Inference]APRL should log which part of a demonstration transfers: plan, sub-goal, motion phrase, or action residual.

Mechanism

The abstract describes structured demonstrations, a dual training design, and inference through the action expert alone to preserve real-time control.

Falsification frontier

If structured demonstrations help only when retrieved scenes closely match training scenes, the method is retrieval similarity rather than reasoning transfer.

Adversarial read

Cross-embodiment transfer needs object, camera, and gripper mismatches; otherwise the structure could hide ordinary imitation bias.

Transferable thinking tool

Treat demonstrations as decomposed evidence objects instead of trajectories to replay.

Strong for VLA manipulation and XR/human-hand transfer; weaker for tasks where language plans are not the bottleneck.

#2Tier A - abstract-only

G0.5: One Autoregressive Stream for Robot Reasoning and Action

autoregressive VLA - reasoning tokens - action tokenizer

Status quo belief

Many VLA systems use a pretrained VLM as a context encoder and rely on a separate action expert for control.

Friction / anomaly

Separating reasoning and action can make prompts steer text while the executable policy follows a different representation path.

Hidden premise

Robot reasoning becomes more controllable if task decomposition, object grounding, action hints, and action tokens share one training stream.

Conceptual move

Emit reasoning and action tokens from a single autoregressive transformer with a cross-embodiment action tokenizer and visual memory.

Evidence trace

  • [Abstract]The paper says the current recipe makes the VLM a context encoder rather than a decision-maker.
  • [Abstract]It interleaves task decomposition, object grounding, action hints, and action tokens under one objective.
  • [Inference]APRL should test whether prompt changes alter action granularity and horizon under the same visual state.

Mechanism

The abstract names a shared action vocabulary, native chain-of-thought stream, and multi-second visual memory through the vision encoder.

Falsification frontier

If reasoning tokens are fluent but do not predict action changes, the shared stream is an explanation layer rather than a control interface.

Adversarial read

Chain-of-thought steering can create brittle prompt dependence; evaluate with equivalent instructions and object distractors.

Transferable thinking tool

Ask whether a reasoning token has motor authority before treating it as robotics evidence.

Strong for language-conditioned robot policies; less direct for low-level controllers without tokenized actions.

#3Tier A - abstract-only

Adaptation of Generalist Robot Policies with Minimal Data

minimal-data adaptation - offline-to-online RL - residual policy

Status quo belief

Fully autonomous robot learning remains blocked by sparse rewards and weak zero-shot exploration.

Friction / anomaly

A generalist policy can know many behaviors yet still fail to discover the first successful trajectory for a new task.

Hidden premise

One or a few demonstrations can anchor the target task enough for autonomous online improvement to become feasible.

Conceptual move

Use behavior cloning on single/few demonstrations, then value-based online RL over a residual policy parameterization.

Evidence trace

  • [Abstract]The paper defines minimal-data adaptation as one demonstration followed by autonomous online interaction.
  • [Abstract]It combines behavior cloning anchoring with value-based online RL on a residual policy.
  • [Inference]APRL should measure how much human guidance is needed before online exploration becomes non-random.

Mechanism

The abstract frames MiDAS as an offline-to-online recipe evaluated on LIBERO and RoboCasa.

Falsification frontier

If residual RL improves only demonstrated variations, it has not crossed into autonomous improvement.

Adversarial read

Sparse reward success can hide unsafe exploration; compare intervention count, failure type, and recovery trajectory.

Transferable thinking tool

Use one-demo bootstrapping as a measurable proxy for autonomous robot improvement.

Strong for manipulation benchmarks with resettable online interaction; weaker for safety-critical hardware without cheap exploration.

#4Tier A - abstract-only

Early Warning Signals for OpenVLA Failure under Visual Distribution Shift

VLA failure monitoring - visual distribution shift - internal activations

Status quo belief

VLA failures are often diagnosed after the task has already failed under visual shift.

Friction / anomaly

A fixed policy can show confident actions while internal activations already contain near-term failure evidence.

Hidden premise

Lightweight probes on feedforward activations can forecast failure without changing the deployed OpenVLA policy.

Conceptual move

Train post-hoc monitors on execution activations and ask whether they predict failure within a fixed horizon.

Evidence trace

  • [Abstract]Occlusion reduces OpenVLA success from 57 percent to 17 percent over 100 episodes per condition.
  • [Abstract]A logistic probe at layer 16 reaches AUROC 0.972 for predicting failure within a 15 step horizon under occlusion.
  • [Inference]APRL should collect warning lead time before evaluating only task success.

Mechanism

The abstract logs OpenVLA activations in LIBERO rollouts and fits lightweight monitors after collection.

Falsification frontier

If the monitor fires only after irreversible contact or does not transfer to other visual shifts, it is a shift detector rather than a failure warning.

Adversarial read

Occlusion is only one stressor; color, camera jitter, viewpoint, and object identity should separate benign shift from task failure.

Transferable thinking tool

Treat internal activations as early warning sensors with lead-time metrics.

Strong for feedforward VLA policies with accessible activations; weaker for black-box closed models.

#5Tier A - abstract-only

Do Not Forget the Obvious - RISC: A Risk-Informed Slice-Coverage Protocol for Safe Autonomous Driving

risk-informed driving evaluation - slice coverage - audit budget

Status quo belief

Aggregate autonomous-driving metrics can look acceptable while high-risk conditions remain under-audited.

Friction / anomaly

A finite validation budget must choose which weather, scene, actor, and perception slices deserve manual or model audit.

Hidden premise

Safety concerns can be translated into machine-readable risk slices and coverage-qualified reports.

Conceptual move

Use risk-guided stress testing plus explicit coverage statements about sufficiently and insufficiently covered slices.

Evidence trace

  • [Abstract]The paper says aggregate metrics may not reflect insufficiently examined high-risk conditions.
  • [Abstract]It instantiates RISC for monocular pedestrian perception using 1,000 frames and a detector proxy.
  • [Inference]APRL should make every driving or robot benchmark publish uncovered risk slices next to the score.

Mechanism

The abstract describes lightweight signals for candidate tagging, compact audit selection by risk, and coverage-qualified reporting.

Falsification frontier

If risk slices are broad or manually chosen after results, coverage qualification can become a reporting label rather than a stress protocol.

Adversarial read

LLM-supported slice discovery should be audited for missed obvious conditions and hallucinated irrelevant slices.

Transferable thinking tool

Every score needs a coverage statement for the risk it does not measure.

Strong for perception, driving, and robotics benchmarks with finite audit sets.

#6Tier A - abstract-only

Herding End-to-End Autonomous Driving via Neuro-Symbolic Safety Guards

driving safety guard - command interface - traceable intervention

Status quo belief

End-to-end driving agents can achieve high average performance while violating basic traffic rules.

Friction / anomaly

A learned agent may not expose or enforce the physical conditions that make a command safe.

Hidden premise

A non-learned rule guard can improve safety if it sits at the final command interface and changes only unsafe actions.

Conceptual move

Attach a lightweight neuro-symbolic guard that checks commands against explicit rules and replaces unsafe commands with nearest safe alternatives.

Evidence trace

  • [Abstract]The guard attaches immediately before commands reach the vehicle.
  • [Abstract]It reports 15 percent Success Rate improvement and up to 53 percent fewer safety-critical collisions in evaluated benchmarks.
  • [Inference]APRL should log every rule intervention as a counterfactual action label.

Mechanism

The abstract reports that each intervention is executable and traceable to the triggering rule without retraining.

Falsification frontier

If guards preserve benchmark score by over-constraining rare maneuvers, they may hide autonomy limits rather than solve them.

Adversarial read

Rules must handle conflicts, sensor uncertainty, and off-policy recovery after intervention.

Transferable thinking tool

Put a traceable contract at the final command boundary.

Strong for driving and mobile robots with explicit command interfaces; weaker for high-dimensional manipulation without simple safety alternatives.

#7Tier A - abstract-only

How Can Driving World Models Do Counterfactual Prediction?

driving world model - counterfactual prediction - abduction action prediction

Status quo belief

Driving world models are often treated as counterfactual simulators for alternative ego actions.

Friction / anomaly

Direct action-conditioned prediction can ignore the factual continuation and produce a plausible future that is not the counterfactual for this episode.

Hidden premise

Counterfactual driving prediction needs abduction from observed evidence before applying the alternative action.

Conceptual move

Formalize the gap using abduction, action, and prediction, then build controlled factual and matched counterfactual outcomes.

Evidence trace

  • [Abstract]The paper identifies a mismatch between counterfactual simulation and direct action-conditioned prediction.
  • [Abstract]It constructs a controlled simulation benchmark with factual and matched counterfactual outcomes.
  • [Inference]APRL should require factual evidence preservation before using a world model for intervention planning.

Mechanism

The abstract evaluates two representative world models and introduces a training-free pipeline that moves observed evidence into the counterfactual view.

Falsification frontier

If abduction helps only on short horizons where other agents do not respond, the result may not scale to interactive traffic.

Adversarial read

Longer horizons and social response break the assumption that surrounding agents evolve independently of the ego change.

Transferable thinking tool

Counterfactual prediction must preserve what actually happened before imagining what could have happened.

Strong for driving evaluation and replay; less direct for manipulation unless factual rollouts have matched counterfactual labels.

#8Tier A - abstract-only

DreamFly: Causal Memory and Receding-Horizon Diffusion Planning for Aerial Vision-Language Navigation

aerial VLN - causal memory - receding-horizon diffusion planning

Status quo belief

Aerial VLN agents must integrate partial observations, plan ahead, and decide when to stop under limited history.

Friction / anomaly

Implicit history and termination can leak future evidence or stop for the wrong reason in partially observable navigation.

Hidden premise

Navigation planning can use future action chunks as auxiliary targets while executing only one action before replanning.

Conceptual move

Combine causally aligned historical memory with receding-horizon diffusion planning and action-logit stop estimation.

Evidence trace

  • [Abstract]The paper names limited historical context, short planning horizons, and unreliable implicit termination as aerial VLN challenges.
  • [Abstract]It uses causally aligned historical memory and receding-horizon diffusion planning.
  • [Inference]APRL should evaluate whether memory improves stop decisions and not only path success.

Mechanism

The abstract describes plan-K execute-one replanning, LiteStop, and memory that uses only observations before the current decision step.

Falsification frontier

If the stop signal improves in static scenes but fails with dynamic distractors, causal memory is not sufficient for outdoor deployment.

Adversarial read

Plan-K execute-one can still optimize short-horizon visibility unless routes include occlusion and dynamic elements.

Transferable thinking tool

Use future action chunks as planning scaffolds, not commitments.

Strong for aerial and mobile navigation; weaker for contact manipulation unless a replanning horizon is explicit.
