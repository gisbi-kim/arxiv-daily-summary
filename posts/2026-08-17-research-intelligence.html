#1Tier A - abstract-only

Evolve Vision-Language-Action Model into an Agent with On-the-fly Tool-use

VLA tool use - modular action space - data-efficient generalization

Status quo belief

End-to-end VLAs usually ask one policy head to cover the full continuous action space.

Friction / anomaly

Dark scenes, novel viewpoints, and low-level perception gaps can make a monolithic action decoder spend data on skills that tools already solve.

Hidden premise

A VLA can learn when to call tool modules without losing the embodied action contract.

Conceptual move

Turn the VLA into an agentic robot interface that injects low-level vision, affordance, and embodiment tools on demand.

Evidence trace

  • [Abstract]ART tunes VLA models to leverage off-the-shelf tool modules for vision, affordance, and embodiment enhancement.
  • [Abstract]The authors report higher success than mainstream baselines on simulation and real-world tasks including dark pick-and-place and novel viewpoints.
  • [Inference]APRL should measure which tool call changed the next action, not only whether the rollout succeeded.

Mechanism

The abstract describes a tool-injection framework, 30K tool-use trajectories, and long-trajectory tool-use reasoning training.

Falsification frontier

If tool calls improve easy visual cases but not out-of-view, low-light, or affordance-confusing cases, the method is extra routing overhead.

Adversarial read

Off-the-shelf tools may leak strong priors; test scenes where the correct tool output is misleading or unavailable.

Transferable thinking tool

Treat action generation as a tool-authority allocation problem.

Strong for modular robot stacks; weaker for hardware where useful tool interfaces are not exposed.

#2Tier A - abstract-only

PRM-as-a-Judge 1.5: A Toolkit for Robot Process Assessment

robot process assessment - progress curves - failure-side diagnostics

Status quo belief

Robot evaluation often compresses a rollout into binary success or a coarse rule-based process score.

Friction / anomaly

A policy can fail late after real progress, recover from drawdown, or succeed with fragile execution, and final success hides those differences.

Hidden premise

Dense progress curves can become evaluation evidence if the evaluator itself is reliability-tested.

Conceptual move

Convert rollout videos into process-reward-model judgments and fine metrics for failure-side progress, recovery, and success-side quality.

Evidence trace

  • [Abstract]The toolkit turns rollout videos into dense progress curves and derives failure-side, recovery, and execution-quality metrics.
  • [Abstract]It includes RoboPulse++ to evaluate process reward model reliability.
  • [Inference]APRL should separate evaluator reliability from robot-policy quality when using video judges.

Mechanism

The abstract introduces new metrics plus RoboPulse++ to test PRM reliability and a reproducible assessment suite.

Falsification frontier

If PRM curves correlate with visual smoothness rather than task-state progress, the judge is not measuring the robot process.

Adversarial read

Test occlusion, camera jitter, similar-looking subgoals, and failed recoveries that appear visually fluent.

Transferable thinking tool

Evaluate the trajectory shape, not only the terminal label.

Strong when rollout videos expose state progress; weaker for tactile or force-critical tasks hidden from camera.

#3Tier A - abstract-only

Reflex: Enabling Fast and Predictive Vision-Language-Action Models for Reaction-Critical Manipulation

reaction-critical manipulation - VLA latency - latent future prediction

Status quo belief

VLA benchmarks usually emphasize static manipulation generalization and under-specify inference latency.

Friction / anomaly

Dynamic manipulation can fail because the policy reasons correctly but reacts after the interaction window has closed.

Hidden premise

A useful VLA for dynamic tasks must couple temporal prediction with an explicit latency budget.

Conceptual move

Build ReflexBench for reaction-critical tasks and a faster VLA with latent future prediction, multi-frame fusion, and deployment optimizations.

Evidence trace

  • [Abstract]ReflexBench decouples simulator stepping from robot control and supports configurable latency.
  • [Abstract]ReflexVLA combines latent future prediction, multi-frame temporal fusion, and reduced deployment latency.
  • [Inference]APRL should report success as a function of allowed reaction time, not only task family.

Mechanism

The abstract describes configurable latency under synchronous/asynchronous inference, batched encoding, and CUDA Graph replay.

Falsification frontier

If gains disappear when latency is equalized against strong baselines, the benefit is systems engineering rather than predictive representation.

Adversarial read

Stress moving objects, delayed observations, and asynchronous controller updates separately.

Transferable thinking tool

Make reaction time an experimental variable in VLA evaluation.

Strong for dynamic manipulation; less direct for slow quasi-static tasks.

#4Tier A - abstract-only

OpenBelief-Nav: Evidence-Preserving Object Memory for Open-Vocabulary Language-Guided Navigation

open-vocabulary navigation - object belief memory - provenance

Status quo belief

Open-vocabulary scene graphs often fuse observations into one label or feature per object.

Friction / anomaly

Early semantic commitment can erase minority but task-relevant hypotheses needed at instruction time.

Hidden premise

Navigation memory should preserve phrase, reliability, mask, and frame provenance until the task readout is known.

Conceptual move

Store observation-level evidence and maintain separate geometric and visual representations for task-specific readout.

Evidence trace

  • [Abstract]The method retains observation-level phrases, reliability cues, and frame-mask provenance.
  • [Abstract]The authors report improvements over early-commit readouts on ScanNet200/Replica and navigation trials.
  • [Inference]APRL should keep conflicting object hypotheses alive until a robot action needs them resolved.

Mechanism

The abstract describes vocabulary-independent object belief, fixed-vocabulary projection, free-form retrieval, and verified candidate attempts.

Falsification frontier

If belief preservation improves segmentation but not target selection under ambiguity, the memory is not action-relevant.

Adversarial read

Use objects with ambiguous labels, occluded affordances, and repeated instances to test when provenance changes the route.

Transferable thinking tool

Do not collapse semantic evidence before the downstream action asks its question.

Strong for navigation and scene memory; weaker for tasks with closed object vocabularies and canonical views.

#5Tier A - abstract-only

hint2: Hierarchical World Models for Inference-Time Temporal Logic Guidance

temporal logic guidance - hierarchical world models - closed-loop policy constraints

Status quo belief

Language-conditioned policies generate short action chunks while temporal-logic constraints are evaluated over long trajectories.

Friction / anomaly

A locally plausible chunk can violate a non-Markovian safety or ordering rule that only appears across the full task.

Hidden premise

High-level proposition transitions and low-level local dynamics can provide complementary guidance at inference time.

Conceptual move

Use hierarchical world models to guide short-horizon policies toward LTL satisfaction without retraining the policy.

Evidence trace

  • [Abstract]The paper derives two guidance objectives from different abstraction levels of world models.
  • [Abstract]The high-level model predicts action-induced transitions in task-relevant atomic propositions.
  • [Inference]APRL should test whether temporal-logic guidance blocks the exact action that would violate the specification.

Mechanism

The abstract separates high-level atomic-proposition progress through an automaton from low-level state-evolution safety guidance.

Falsification frontier

If LTL satisfaction improves only on specs with easy proposition labels, the guidance may not survive real perceptual uncertainty.

Adversarial read

Stress ambiguous proposition detection, delayed effects, and safety rules that conflict with progress.

Transferable thinking tool

Split long-horizon constraints into proposition progress and local safety signals.

Strong for instruction-following manipulation with symbolic milestones; weaker when predicates cannot be grounded reliably.

#6Tier A - abstract-only

Ontology-Grounded World Models for Failure Diagnosis and Closed-Loop Repair in Physical AI Systems

failure diagnosis - ontology interface - verification-gated repair

Status quo belief

World-model repair can report quality scores without naming the failed task predicate or the allowed correction route.

Friction / anomaly

A repair loop is hard to trust if failed predicates, arguments, and post-correction acceptance are not retained.

Hidden premise

Symbolic task-local records can make learned or heuristic proposers auditable without replacing the world model.

Conceptual move

Layer an ontology-grounded diagnosis and verification-gated correction interface above EV-WM.

Evidence trace

  • [Abstract]Onto-EV-WM records unmet task predicates, route labels, and post-correction acceptance results.
  • [Abstract]The interface keeps learned or heuristic proposers separate from native predicate verification.
  • [Inference]APRL should require every repair proposal to carry the predicate it claims to fix.

Mechanism

The abstract describes task-local TBox/ABox grounding, deterministic rule retention, route labels, and bounded retry verification.

Falsification frontier

If predicate records do not improve correction selection beyond a tuned continuous score, the ontology adds bookkeeping without control value.

Adversarial read

Test failures where the same visible state supports multiple missing predicates or where a repair fixes one predicate and breaks another.

Transferable thinking tool

Make failure repair answerable to named predicates and bounded retries.

Strong for task families with explicit predicates; weaker for open-ended manipulation where predicate design is unstable.

#8Tier A - abstract-only

Coverage Aware Active Evaluation for Failure Discovery with Paired Systems

failure discovery - proxy systems - target-risk selection

Status quo belief

Autonomous-system testing often samples real target failures sparsely because target evaluations are expensive.

Friction / anomaly

Proxy failures from simulators or related policies do not transfer cleanly to the real target system.

Hidden premise

Proxy signals are useful only after a local residual model corrects their target-risk error and keeps scenario coverage realistic.

Conceptual move

Combine proxy evaluations with limited target results to actively select diverse, well-supported failure scenarios.

Evidence trace

  • [Abstract]The method learns a local predictor of target risk by correcting proxy failure signals.
  • [Abstract]Across driving, manipulation, and quadruped tasks, it discovers up to two times as many failures as random sampling and active-learning baselines.
  • [Inference]APRL should report which proxy failures transferred and which target failures proxies missed.

Mechanism

The abstract describes control-variate-inspired residual modeling and a support-aware mutual-information objective.

Falsification frontier

If proxy correction overfits early target failures, it may stop discovering rare but severe new modes.

Adversarial read

Use proxy systems with systematic blind spots and hold out one failure family from initial target labels.

Transferable thinking tool

Spend real robot tests where proxy disagreement and scenario support jointly predict severe failure.

Strong for expensive robot or driving evaluations; weaker when target tests are already cheap and exhaustive.
