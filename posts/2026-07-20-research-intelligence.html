Xiaomi-Robotics-1: Scaling Vision-Language-Action Models with over 100K Hours of Real-World Trajectories

VLA scaling - real-world trajectory pre-training - cross-embodiment post-training · abstract · PDF

1. 지배적 믿음

로봇 VLA는 web-scale VLM과 달리 teleoperation data가 느리고 좁아서 scaling law를 그대로 적용하기 어렵다는 인식이 강합니다.

2. 관찰된 마찰

저자들은 robot data bottleneck을 UMI trajectory와 auto-labeling으로 우회해야 한다고 보고, state-transition language와 imperative robot instruction 사이의 prompt mismatch를 post-training 문제로 분리합니다.

3. 숨은 전제

대규모 robot pre-training의 병목은 trajectory 수만이 아니라, 행동을 어떤 language-conditioned state transition으로 라벨링해 나중에 embodiment instruction으로 다시 맞출 수 있는가입니다.

4. 개념적 이동

100k 시간 UMI trajectory를 VLM auto-labeling으로 state-transition prompt에 묶고, 이후 10k 시간 cross-embodiment data로 robot embodiment와 imperative instruction에 정렬하는 two-stage recipe를 제안합니다.

5. 작동 메커니즘

Mixture-of-Transformers 구조에서 Qwen3-VL 계열 VLM은 observation/language와 KV cache를 제공하고, DiT는 robot state와 VLM cache를 조건으로 action chunk를 flow matching으로 생성합니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]100k 시간 real-world UMI trajectory pre-training, auto-labeled state-transition prompt, cross-embodiment post-training의 전체 recipe를 제시합니다.
  • Figure 2 [Verified]VLM KV cache와 robot proprioceptive state를 조건으로 DiT action chunk를 생성하는 MoT architecture를 설명합니다.
  • Section 3.1 / Figure 5 [Verified]20k 시간 UMI subset에서 data scale과 model scale이 validation action MSE를 낮추며, data scale effect가 더 크다고 분석합니다.
  • Section 3.2 / Figure 8 [Verified]pre-training data 0%에서 100%로 갈수록 unseen-environment post-training success가 26%에서 75%로 증가한다고 보고합니다.
  • Section 3.3 [Verified]평균 10시간 미만 task data로 네 개 held-out dexterous/mobile tasks에서 75% success를 보이고 pi0.5의 40%와 비교합니다.

7. Falsification frontier

같은 10k post-training budget에서 더 작고 다양하게 curated된 dataset이 비슷한 unseen-environment success를 내거나, state-transition auto-label을 제거해도 scaling transfer가 유지되면 large UMI labeling recipe의 핵심성은 약해집니다.

8. Adversarial read

강한 결과는 매우 큰 proprietary trajectory corpus와 in-house robot data에 의존합니다. public reproduction 가능성, data diversity의 정확한 coverage, failure cases, low-cost lab transfer는 별도 검증이 필요합니다.

9. 훔칠 사고 도구

로봇 scaling을 model size가 아니라 labelable state transition, embodiment alignment, low-data transfer의 세 계약으로 나누어 봅니다.

10. Transfer boundary

대규모 data infra가 있는 팀에는 직접적이지만, APRL 규모에서는 100k 시간 재현보다 OOD composition과 small-data adaptation harness를 소유하는 쪽이 더 현실적입니다.

AC-VLA: Robust Out-of-Distribution Action Execution via Compositional Learning

VLA OOD generalization - sub-skill composition - visual shortcut suppression · abstract · PDF

1. 지배적 믿음

end-to-end VLA는 충분한 demonstrations를 보면 pick/place 같은 familiar skills를 novel instruction에도 재조합한다고 기대하기 쉽습니다.

2. 관찰된 마찰

논문은 OOD recombination에서 holistic trajectory memorization과 wrist-view texture shortcut이 서로 보강되어, language instruction과 global spatial grounding이 무시될 수 있다고 봅니다.

3. 숨은 전제

compositional OOD failure는 하나의 model-capacity 문제가 아니라 sub-task semantic supervision과 view-dependent shortcut을 동시에 분리해야 드러나는 failure family입니다.

4. 개념적 이동

LLM instruction decomposer와 proprioceptive trajectory aligner로 dense sub-task supervision을 만들고, full demonstration과 decomposed segments를 mixed training합니다. closed-gripper place phase에서는 wrist-view input을 mask해 global grounding을 강제합니다.

5. 작동 메커니즘

Figure 2는 compositional learning module과 state-conditioned asymmetric masking을 architecture modification 없이 VLA backbone에 붙이는 방식을 보여줍니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]training에서는 object A->target A, object B->target B만 보았을 때 novel object A->target B가 visual/language token conflict를 만든다고 설명합니다.
  • Section 3.2 [Verified]full trajectories와 decomposed sub-task data를 고정 ratio로 섞어 long-horizon coherence와 primitive recombination을 함께 학습합니다.
  • Section 3.3 [Verified]closed-gripper phase에서 wrist-camera view를 suppress해 local texture shortcut 대신 third-person global spatial context를 쓰게 합니다.
  • Table 2 [Verified]LIBERO-OOD Spatial/Goal에서 AC-VLA(pi0.5)가 64.2/73.3 success를 보고하며 vanilla pi0.5 대비 28.7/26.7 absolute gain을 제시합니다.
  • Table 4 [Verified]real-world setup에서 baseline pi0.5는 OOD 35.0%, AC-VLA는 OOD 82.5% success를 보고합니다.

7. Falsification frontier

task templates와 object-target combinations를 충분히 다양하게 늘린 vanilla VLA가 같은 OOD split에서 비슷하게 올라가거나, wrist masking이 다른 camera geometry에서는 성능을 해치면 shortcut 가설은 조건부로 약해집니다.

8. Adversarial read

offline decomposition은 LLM semantic parser와 proprioceptive aligner 오류에 민감합니다. 저자도 ambiguous/domain-specific instruction에서 sub-task description 오류가 trajectory alignment에 전파될 수 있다고 적습니다.

9. 훔칠 사고 도구

VLA OOD를 평균 success로 보지 말고 trajectory overfitting과 perceptual shortcut을 서로 다른 intervention으로 분리합니다.

10. Transfer boundary

tabletop recombination에는 직접적이지만 deformable/contact-rich tasks에서는 sub-skill boundary와 wrist masking phase가 더 모호해질 수 있습니다.

Think at 5 Hz, Act at 20 Hz: Asynchronous Fast-Slow Vision-Language-Action Inference for Closed-Loop Driving

closed-loop driving VLA - asynchronous cache - action expert latency · abstract · PDF

1. 지배적 믿음

language-conditioned driving agent는 매 control tick마다 큰 VLA가 scene history를 다시 읽거나, 느리면 command replay로 frame skipping을 감수합니다.

2. 관찰된 마찰

7B backbone이 20Hz closed-loop control rate를 맞추지 못해, 기존 LMDrive 계열은 alternate tick만 model을 호출하고 나머지는 stale command를 재사용합니다.

3. 숨은 전제

instruction understanding과 scene aggregation은 느리게 갱신되어도 되지만, current-frame-to-waypoint mapping은 빠르게 매 tick 갱신되어야 합니다.

4. 개념적 이동

frozen 7B VLA backbone은 low-frequency slow system으로 KV cache를 유지하고, 337M action expert가 매 50ms tick마다 cache와 current frame에 cross-attend해 waypoint를 예측합니다.

5. 작동 메커니즘

expert는 backbone per-layer KV cache를 읽지만 backbone은 expert token을 보지 않으므로 cache가 동일하게 유지됩니다. randomized staleness training은 deployment cache lag를 학습 분포에 넣습니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]baseline frame-skipping agent는 89ms invocation 때문에 50ms tick마다 fresh control을 만들지 못하고, expert path는 32ms per tick을 제시합니다.
  • Figure 2 [Verified]slow backbone이 K=4 tick마다 four visual tokens를 cache에 append하고, fast expert가 매 tick 10 tokens로 cached keys/values를 읽는 구조를 보여줍니다.
  • Table 2 [Verified]LangAuto-Short town05에서 route completion이 frame-skipping baseline 37.0에서 94.0으로 상승하고, same expert 10Hz ablation은 82.1입니다.
  • Table 3 / Figure 5 [Verified]legacy recompute cost는 history length에 따라 59-169ms로 증가하지만 cached expert model cost는 약 32ms로 flat하다고 보고합니다.
  • Section 4 / limitations discussion [Verified]town03 long routes에서는 completion은 85.4%지만 collisions/red-light penalties로 driving score가 무너져 hazard negotiation은 아직 약하다고 분석합니다.

7. Falsification frontier

short-context state abstraction이나 smaller synchronous backbone이 같은 latency budget에서 route completion과 infraction score를 동시에 맞추면, per-layer cache interface의 독립 가치는 줄어듭니다.

8. Adversarial read

completion gain은 강하지만 infraction trade-off가 남아 있습니다. long-route dense traffic과 signalized encounter가 부족한 training distribution에서는 fresh control이 더 멀리 가서 더 많은 위험에 노출될 수 있습니다.

9. 훔칠 사고 도구

큰 model을 줄이기보다 slow context와 fast control의 갱신 주기를 분리하고, staleness를 training variable로 만듭니다.

10. Transfer boundary

VLA driving과 low-frequency reasoning에 강하지만 high-rate contact reflex나 safety-certified controller에는 별도 fast safety layer가 필요합니다.

Orbis 2: A Hierarchical World Model for Driving

driving world model - hierarchy - diffusion forcing representation learning · abstract · PDF

1. 지배적 믿음

driving world model은 single-level latent에서 frame-by-frame future를 만들고 FVD 같은 perceptual fidelity로 주로 평가됩니다.

2. 관찰된 마찰

저자들은 long-horizon dynamics에는 coarse semantic/structural latent가 필요하지만, visual rollout에는 fine detail latent가 필요하다고 보고 두 objective를 한 representation에 묶는 것을 병목으로 봅니다.

3. 숨은 전제

world model의 useful representation은 보기 좋은 pixel detail보다 spatial/semantic structure와 steering response를 보존해야 downstream driving에 유효합니다.

4. 개념적 이동

2Hz abstract high-level predictor가 compressed DINO-aligned latent에서 long-horizon subgoal을 만들고, 10Hz low-level predictor가 그 subgoal을 조건으로 short-horizon detailed frames를 생성합니다.

5. 작동 메커니즘

abstract predictor는 diffusion forcing으로 pre-train한 뒤 teacher forcing으로 fine-tune하고, low-level detail predictor는 teacher forcing으로 pixel-aligned rollout을 맞춥니다.

6. 결정적 증거와 Evidence Trace

  • Figure 1 [Verified]abstract predictor가 long horizon latent state를 예측하고 detail predictor가 high-level prediction에 조건화된 frame을 생성하는 hierarchy를 제시합니다.
  • Section 3 [Verified]compressed DINO latent는 16-dimensional abstract space로, high-level flow-matching predictor의 안정적 rollout을 위해 설계됩니다.
  • Table 2 [Verified]FVD, FVD-slope, semantic segmentation probing, depth probing을 함께 보고 perceptual fidelity와 representation quality를 동시에 평가합니다.
  • Table 5 [Verified]diffusion forcing pre-training 후 teacher forcing fine-tuning이 semantic mIoU 58.29, depth RMSE 4.157로 가장 좋은 probing 결과를 낸다고 보고합니다.
  • Conclusion / Limitations [Verified]diffusion forcing이 왜 representation을 개선하는지는 완전히 분리해 연구하지 않았고, abstract/detail latent interaction이 제한된다고 밝힙니다.

7. Falsification frontier

single-branch mixed abstraction model이나 action-conditioned flat predictor가 equal compute에서 같은 FVD-slope와 probing 성능을 얻으면 hierarchy의 필요성은 줄어듭니다.

8. Adversarial read

strong internal representation과 steering responsiveness가 closed-loop planning success로 직접 이어지는지는 외부 planner/policy 연결 실험이 더 필요합니다.

9. 훔칠 사고 도구

world model을 pixel prediction machine이 아니라 abstraction level, temporal resolution, training corruption schedule의 조합으로 설계합니다.

10. Transfer boundary

driving video world model에는 직접적이지만 robot manipulation에서는 contact, force, object permanence처럼 pixel latent 밖의 state가 추가로 필요합니다.

ImprovedVBGS: Real-time Continual Variational Bayes Gaussian Splatting

continual Gaussian reconstruction - real-time map update - memory/latency contract · abstract · PDF

1. 지배적 믿음

continual Gaussian Splatting은 replay-free learning이 가능해도 per-frame iterations over all observed points 때문에 robot online mapping에는 너무 느리다고 보기 쉽습니다.

2. 관찰된 마찰

VBGS의 CAVI update는 모든 observed point와 component assignment를 다루기 때문에 strict memory/latency requirement가 있는 robotics navigation에 맞지 않습니다.

3. 숨은 전제

robot map으로 쓰려면 reconstruction quality뿐 아니라 새 frame이 들어왔을 때 posterior update가 bounded latency 안에서 끝나야 합니다.

4. 개념적 이동

spatially truncated variational E-step으로 nearby Gaussian components만 평가하고, reassignment forwarding/truncation으로 wasteful recomputation을 줄입니다.

5. 작동 메커니즘

KD-tree로 spatial means의 C nearest candidates를 찾고 truncated E-step에서 responsibilities와 ELBO를 계산합니다. reassignment는 fit step에서 이미 계산된 ELBO를 forward합니다.

6. 결정적 증거와 Evidence Trace

  • Abstract / Section 1 [Verified]NeRF Synthetic에서 mean per-frame latency를 84.0s에서 0.050s로 줄여 1680x speed-up을 보고합니다.
  • Algorithm 1 [Verified]spatially truncated E-step은 KD-tree candidate pruning으로 nearest component subset만 평가합니다.
  • Table 1 [Verified]RTX 3070 Ti, random initialization, static-shape reassignment protocol에서 latency와 PSNR을 scene별로 보고합니다.
  • Table 2 [Verified]cumulative ablation으로 truncation, reassignment forwarding, batch-size change가 latency/quality trade-off에 주는 영향을 분리합니다.
  • Figure 2 [Verified]baseline fit step의 compute_elbo_delta 28.8s/frame과 sum_stats 24.3s/frame bottleneck이 ImprovedVBGS에서 ms scale로 줄었다고 분석합니다.

7. Falsification frontier

dynamic scene, rolling shutter, noisy pose, loop closure가 들어간 robot trajectory에서 latency advantage가 PSNR만 유지하고 localization/map consistency를 해치면 robot-usable map claim은 약해집니다.

8. Adversarial read

평가는 NeRF Synthetic static scenes 중심입니다. robot navigation에 필요한 pose uncertainty, dynamic object update, closed-loop localization success는 별도 측정이 필요합니다.

9. 훔칠 사고 도구

3DGS 연구를 rendering quality 경쟁이 아니라 posterior update latency와 map usability contract로 다시 읽습니다.

10. Transfer boundary

on-the-fly static reconstruction에는 강하지만 active SLAM, semantic map, dynamic object handling에는 pose and update-policy layer가 필요합니다.

#6Tier A - official arXiv HTML verified

VTLoc: Learning-based Tactile Contact Localization in Visual Point Clouds

visual-tactile localization - 3D point cloud contact state - manipulation sensing · abstract · PDF

1. 지배적 믿음

tactile contact localization은 object-specific codebook이나 same-dimensional matching에 기대기 쉬워, 2D tactile image를 3D object surface에 직접 맞추기 어렵습니다.

2. 관찰된 마찰

touch는 local signal이고 vision은 global geometry라서, tactile reading과 point cloud surface 사이의 spatial alignment ambiguity가 contact-rich manipulation 병목이 됩니다.

3. 숨은 전제

contact state를 action policy에 쓰려면 tactile feature를 3D object geometry 위의 probability distribution으로 바꿔야 합니다.

4. 개념적 이동

Geometric Multi-Modal Alignment가 fused visual-tactile feature에서 pseudo-point cloud를 reconstruct하고 원본 point cloud와 align하며, Iterative Localization Updater가 contact coordinate를 반복 refinement합니다.

5. 작동 메커니즘

final contact estimate는 candidate contact set에서 top-K likelihood를 만들고, point cloud 위에 3D contact probability heat-map을 생성합니다.

6. 결정적 증거와 Evidence Trace

  • Figure 3 [Verified]GMA가 pseudo-point cloud와 original point cloud의 Chamfer alignment를 만들고 ILU가 contact location을 반복 수정하는 workflow를 제시합니다.
  • Figure 4 / Dataset section [Verified]ObjectFolder Real 기반 100 real-world objects, object당 30-50 contact locations, 1024 point samples로 benchmark를 구성합니다.
  • Table II-III [Verified]non-uniform subset에서 VTLoc이 Point Filtering 대비 ND 14.87%, Top-5 Acc 30.19% 개선, uniform subset에서도 baseline 대비 개선을 보고합니다.
  • Table IV [Verified]multi-contact localization에서 non-uniform ND가 single-contact 20.17%에서 4.85%로 감소하고 MidasTouch 8.76%보다 낮다고 보고합니다.
  • Conclusion and Discussion [Verified]flat/symmetric surfaces에서는 tactile ambiguity가 본질적으로 남고, soft objects에는 temporal tactile sequence가 필요하다고 제한을 밝힙니다.

7. Falsification frontier

unknown soft objects, deformable contact, in-hand rotation under occlusion에서 probability heat-map이 action recovery를 개선하지 못하면 contact localization gain은 perception-only gain으로 제한됩니다.

8. Adversarial read

symmetry prior는 manually specified axis에 의존하고, hard objects 중심입니다. downstream manipulation success와 failure-warning lead time은 아직 직접 평가되지 않았습니다.

9. 훔칠 사고 도구

touch를 binary contact event가 아니라 3D geometry 위의 uncertainty map으로 바꾸고, action update가 어느 ambiguity를 줄이는지 봅니다.

10. Transfer boundary

rigid object contact localization에는 직접적이지만 soft/deformable manipulation이나 high-speed tactile servoing에는 temporal model과 control loop 검증이 필요합니다.

🔗 Cross-paper decision synthesis

S1 - scale과 composition은 같은 VLA 문제가 아니다

Xiaomi-Robotics-1 - AC-VLA - IMBench

논문 사실 · Xiaomi는 data/model scale이 post-training success로 이어진다고 보고, AC-VLA는 familiar sub-skills의 OOD recombination에서 별도 failure mode를 보입니다.

APRL inference · APRL은 large-data scaling을 그대로 따라가기보다, small-data adaptation과 composition OOD split을 결합한 evaluation asset을 소유해야 합니다.

결정 · VLA 실험의 기본 split을 ID success, composition OOD, shortcut view ablation, low-data transfer로 고정합니다.
